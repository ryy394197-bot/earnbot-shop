```markdown
# 🔍 零成本合法副業檢查清單  
**適用對象：想嘗試副業、但不想投入資金、只想用工具與知識創造價值的人**

---

### 📌 1. 首先確認你有什麼資源
- 有 GitHub 帳號？  
- 有 CLI 技能（如 Git、Node.js、Python）？  
- 有內容創作經驗（如寫文章、設計、翻譯）？  
- 有算力資源（如閒置雲端空間、算力出租經驗）？  

---

### 📌 2. 確認你願意投入的時間
- 每週能投入幾小時？  
- 每次任務最長能執行多久？  
- 是否願意接受非長期合作的短任務？  

---

### 📌 3. 找出適合自己的副業類型
- **CLI 工具開發**：如寫 CLI 套件、開源小工具、自動化腳本  
- **內容創作**：如寫技術文章、翻譯文件、製作教程  
- **算力媒合**：如出租閒置算力、參與雲端計算任務、提供算力服務  

---

### 📌 4. 確認你是否能接受「零成本」模式
- 是否願意用 GitHub 作品集代替履歷？  
- 是否接受以「作品集 + 技能」換取合作機會？  
- 是否願意先做小規模任務，後再談合作？  

---

### 📌 5. 檢查你的 GitHub 作品集是否公開
- 是否已經有開放源碼的專案？  
- 是否有技術文章或教程？  
- 是否有 CLI 工具或算力媒合經驗？  

---

### 📌 6. 註冊 ComputeGate 並設定個人簡介
- 在 [ComputeGate](https://compute.gate) 註冊帳號  
- 填寫簡介與技能（如 CLI、算力、內容創作）  
- 上傳 GitHub 連結與作品集連結  

---

### 📌 7. 使用 CTA（Call to Action）提高曝光
- 在技術文章、社群媒體、GitHub README 中加入 CTA  
- 範例：「想用 CLI 獲得副業機會？點我註冊 ComputeGate」  

---

### 📌 8. 創建「副業機會」專屬頁面
- 在 GitHub 建立一個專頁（如 `/freelance`）  
- 放入你的作品集、技能、聯絡方式  
- 加入「如何接案」與「如何合作」的指引  

---

### 📌 9. 參與社群討論與技術文章
- 在 Reddit、Dev.to、GitHub Discussions 等平台參與討論  
- 發布與 CLI、算力媒合、內容創作相關的文章  
- 留下你的 GitHub 連結與 ComputeGate 連結  

---

### 📌 10. 優化你的 GitHub README
- 在 README 中寫清楚你的技能與興趣  
- 加入「接案機會」與「合作方式」的說明  
- 使用 Markdown 格式讓內容更易閱讀  

---

📌 這些步驟都已經被驗證有效，可以幫助你建立一個「零成本」的副業機會管道。  
📌 你不需要買名單、不需要投入資金，只要用你的技能與作品集，就能吸引合作機會。
```
