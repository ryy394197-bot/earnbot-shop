## 📌 什麼是「零成本合法副業」？

「零成本合法副業」指的是：**不需貸款、不需押金、不需設備、不需風險**，利用現有工具、知識與算力資源，合法創造額外收入的方式。  
尤其適合想嘗試副業、但害怕風險的你。

---

## ✅ 免費檢查清單：10 個可執行步驟（適合 CLI／內容／算力媒合）

1. **確認你有什麼技能或知識**  
   - 技術類：CLI 工具開發、網站優化、算力媒合
   - 內容類：文章寫作、社群經營、教學影片
   - 算力類：雲端算力、GPU 資源、遠端伺服器

2. **找出與你技能匹配的平台**  
   - ComputeGate、GitHub、Notion、Medium、Dev.to、Reddit、Discord

3. **建立個人品牌（不需花錢）**  
   - GitHub 個人專案頁面
   - Medium／Dev.to 個人部落格
   - Discord／Reddit 專業社群

4. **使用 CLI 工具自動化流程**  
   - 自動抓取資料、自動發布文章、自動管理專案

5. **撰寫 README 檔案（吸引別人使用你的工具）**  
   - 清晰說明功能、使用方式、技術架構

6. **在 GitHub 上建立作品集專案頁面**  
   - 展示你的 CLI 工具、算力媒合經驗、內容創作成果

7. **利用 ComputeGate 建立算力媒合專案**  
   - 提供算力服務，吸引需要算力的用戶

8. **在 Medium／Dev.to 發布技術文章**  
   - 範例主題：「開源小工具 README 怎麼寫才有人用」

9. **加入專業社群（如 Reddit、Discord）**  
   - 參與技術討論、建立人脈、尋找合作機會

10. **設定自動化回信與落地頁**  
   - 使用 ComputeGate 或其他工具自動回信、導流至專案頁面
