### 开源/内容创作者赞助变现包

#### GitHub Sponsors 與 Ko-fi 哪個先開
在開始之前，我們先來比較一下 GitHub Sponsors 和 Ko-fi 這兩種不同的贊助模式。GitHub Sponsors 提供了更簡單、直接的贊助體驗，並且可以自動更新存取權限，讓用戶更容易理解自己的贊助級別。Ko-fi 網站則提供了更多的回饋和互動機會，例如專屬頻道和社群活動。

#### 三檔贊助價位與回饋方案
我們將提供三種不同的贊助價位，並為每個級別制定相應的回饋方案。請注意，這些收入預估僅供參考，實際情況可能有所不同。

1. **基本級（$5/月）**
   - 回饋：獲得 GitHub Sponsors 贊助者標誌、專屬頻道訪問權限。
   - 附加回饋：參與專題討論和小組會議。

2. **中級級別（$10/月）**
   - 回饋：獲得所有基本級回饋，以及每月一次的專題分享會機會。
   - 附加回饋：優先參與內容創作、早期測試版體驗。

3. **高階級（$25/月）**
   - 回饋：獲得所有中級級別回饋，並享有長期合作機遇。
   - 附加回饋：與作者進行一對一諮詢會話、專屬活動邀請函。
