**開源內容創作者贊助變現包**

### GitHub Sponsors vs Ko-fi 哪個先開？

*   GitHub Sponsors 是由 GitHub 提供的贊助平台，允許開源專案贏得贊助。
*   Ko-fi 是一個平台，讓內容創作者能夠收到小額贊助。

### 個人頁一句定位

*   定義你是誰、你做什麼以及你想要的贊助形式。

    ```markdown
## 我的簡介

我是一名專注於開源內容創作的工程師，致力於推動技術教育和分享經驗。我正在尋找贊助者來支持我的工作。
```

### 三檔贊助價位與回饋

*   提供不同級別的贊助價位，並解釋每個級別的贊助者將收到的內容回饋。

    ```markdown
## 贊助價位

### Basic - 10 TWD/月
支援我的基本開源活動，包括 GitHub Sponsors 和 Ko-fi 的贊助。

### Premium - 50 TWD/月
獲得優先評估和反饋，以及專屬 Discord 伺服器的存取權。

### Elite - 100 TWD/月
享受全部 Premium 权限，並且還將收到一份免費的技術教育課程。
```

### README／文章 CTA 範本

*   為你的README或文章提供贊助連結和CTA（呼喚動作）。

    ```markdown
## 贊助我的工作！

如果您支持我的內容創作，請考慮贊助我。您的贊助將有助於我繼續推動開源內容創作。

[GitHub Sponsors](https://github.com/sponsors/your-username)
[Ko-fi](https://ko-fi.com/your-username)
```

### Threads 招募贊助貼文

*   在Threads上發布一則招募贊助的貼文，並附上贊助連結。

    ```markdown
## 需要您的支持！

我是一名開源內容創作者，致力於推動技術教育和分享經驗。我正在尋找贊助者來支持我的工作。如果您也想要贏得更多贊助，請考慮加入我們的團隊！[GitHub Sponsors](https://github.com/sponsors/your-username) [Ko-fi](https://ko-fi.com/your-username)
```

### 禁止事項

*   避免假數據和買粉絲等不道德行為。

    ```markdown
## 禁止事項

*   假數據：避免將不存在的贊助者或收入作為例子。
*   買粉：不要購買虛假的粉絲或贊助者，盡量維持自然的贊助流程。

```

規則：保持真實、合法和零墊資。
