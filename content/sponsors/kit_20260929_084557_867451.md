## 贊助價位與回饋
### 低檔贊助（$10/月）
- **回饋:** 現金回饋 $5、贊助者名稱標示於創作者頁面。
### 中檔贊助（$25/月）
- **回饋:** 現金回饋 $10、贊助者名稱標示於創作者頁面、個人專欄推薦。
### 高檔贊助（$50/月）
- **回饋:** 現金回饋 $20、贊助者名稱標示於創作者頁面、個人專欄推薦、邀請參與內容合作。

### GitHub earnbot-shop
- **GitHub earnbot-shop** 將會自動將您的贊助價位與回饋顯示在 GitHub 上，增加曝光率及吸引更多贊助者。
- **注意:** 請使用FUNDING.yml格式設定價格與回饋內容。

### Ko-fi 為選用
- **Ko-fi** 是一個提供給創作者支付的平臺，可以透過購買點數來支持他們。請確認您已加入Ko-fi並設置好贊助價位及回饋。
