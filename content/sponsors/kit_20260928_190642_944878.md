### 創作者支援與變現包

#### 一、目標
為您提供一套整合的方案，協助創作者在社群媒體上建立一個穩定的贊助渠道，讓您的作品得到支持並產生收入。

#### 二、服務內容
1. **定位句**
   - 精選的個人頁一句定位短語，幫助您在社群媒體上塑造清晰的品牌形象。
2. **贊助價位與回饋**
   - 提供三種不同檔次的贊助價格及相應的回饋內容，讓創作者根據自己的需求選擇合適的支援方案。
3. **README／文章 CTA 範本**
   - 完成的 README 以及文章中的 CTA（Call to Action）範本，方便您快速上手並應用於作品中。
4. **招募贊助短貼**
   - 配備一則簡潔易懂的招募贊助短貼，協助創作者更容易吸引粉絲關注。
5. **禁止事項**
   - 明確列出禁止行為，確保您的社群環境健康、誠實。

#### 三、系統功能
- 系統會自動將 FUNDING.yml 與 CTA 推送至 GitHub earnbot-shop，方便管理與更新。
- Ko-fi 為選用方案，您可根據需要選擇適用的平台。

#### 四、使用說明

1. **個人頁一句定位**
   - 根據您的作品特質及目標粉絲群體，撰寫一個精簡而有力的一句話定位短語。建議在個人頁或介紹中使用。
2. **贊助價位與回饋**
   - 設定三種不同檔次的贊助價格，並提供相應的回饋內容（詳見 README）。請注意，該系統不保證收入，僅作為參考。
3. **README／文章 CTA 範本**
   - 使用提供的 README 以及文章中的 CTA 視頻範本，將其嵌入到您的作品中。這些範本已確保一致性與專業性。
4. **招募贊助短貼**
   - 將提供的招募贊助短貼置於個人頁或社群媒體上，以吸引粉絲關注並進行支援。

#### 五、禁止事項
- 禁止提供假數據或虛假的回饋內容。
- 禁止購買粉絲或利用其他手段增加贊助數量。

- 需注意系統更新與功能改進。
