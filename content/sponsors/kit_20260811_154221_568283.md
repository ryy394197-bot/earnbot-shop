### GitHub Sponsors 與 Ko-fi 哪個先開
GitHub Sponsors 先於 2020 年 6 月正式推出，允許開源貢獻者接收贊助。Ko-fi 則於 2014 年創立，是一個社區支持平台，讓創作者可以通過小額贊助來獲得收入。

### 三檔贊助價位與回饋
| **贊助等級** | **回饋內容** |
| --- | --- |
| **Silver** ($5) | 個人頁免費升級，Logo顯示 30 天，專用 Discord 號碼 |
| **Gold** ($20) | 上述 Silver 回饋 + 月度私信，Logo顯示 3 個月，專用 Discord 號碼 |
| **Platinum** ($50) | 上述 Gold 回饋 + 季度私信，Logo顯示 6 個月，專用 Discord 號碼 |
