# Open Source / Creator Sponsorship Package

## 一、個人頁一句定位
### 定位範例：
- 「『[你的頻道名稱]』是 [你的興趣或專長] 的專業分享地點，讓你有更多機會與粉絲進行互動。贊助我們可以幫助你提升內容品質，並讓更多人看到你的作品。」

## 二、三檔贊助價位與回饋
### 第一級：基本支持（$10/月）
- 回饋：「[你的頻道名稱]」的粉絲專區加入贊助者標誌，歡迎你分享更多內容。
- 回報頻率：每月一次。

### 第二級：積極支持（$25/月）
- 回饋：「[你的頻道名稱]」的粉絲專區加入贊助者標誌，歡迎你分享更多內容；每月贈送 1000 元的觀看券。
- 回報頻率：每月一次。

### 第三級：全力支持（$50/月）
- 回饋：「[你的頻道名稱]」的粉絲專區加入贊助者標誌，歡迎你分享更多內容；每月贈送 1000 元觀看券；每季一次訪談邀請，與粉絲互動。
- 回報頻率：每月一次。

## 五、禁止事項（假數據、買粉）
### 禁止事項：
- 不得使用假數據或購買粉絲。
- 不得進行虛假宣傳，如「每月贈送觀看券」等。

## 七、說明
### 建議操作步驟：
1. 在 GitHub 上建立專案或更新現有專案的 README。
2. 將上述內容填入 README 中。
