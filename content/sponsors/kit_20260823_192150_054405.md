## 前言
在這個內容為王的時代，開源/内容创作者想要找到一個有效的變現方式，除了傳統廣告、商標授權等方法外，也可以考慮與社群平台合作，例如 GitHub Sponsors 與 Ko-fi。本包裝將提供你 GitHub Sponsors 與 Ko-fi 的選擇建議、個人頁面定位、三檔贊助價位與回饋設計、README / 文章 CTA 範本、一則 Threads 招募贊助貼文，以及禁止事項。

## GitHub Sponsors 與 Ko-fi 的選擇
GitHub Sponsors 是一個專為 GitHub 上的開源/内容创作者服務的功能，讓有興趣支持你工作的社群成員可以直接付費支援。而 Ko-fi 也是一個眾多內容創作者使用來獲取贊助的平台，兩者各有優缺點。

### GitHub Sponsors
- **優點**：
    - 可以直接在個人頁面看到贊助數量。
    - 資訊透明度高。
    - 有較高的轉化率。
- **缺點**：
    - 需要等待 Github 檢核，時間可能長一些。

### Ko-fi
- **優點**：
    - 簡易快速上手。
    - 可以直接收到現金。
- **缺點**：
    - 資訊透明度較低。
    - 轉化率相對較低。

根據你的需求和目標，你可以選擇 GitHub Sponsors 或 Ko-fi。如果你希望有更高的轉化率並保持資訊透明度，建議使用 GitHub Sponsors；反之則可考慮 Ko-fi。

## 个人页面定位
在設計個人頁面時，請注意以下幾個點：
- **故事性**：清晰地描述你的背景、經歷及創作理念。
- **獨特性**：突出你與其他開源/内容创作者的不同之處。
- **連結導向**：將贊助連結放在顯眼位置。

---

## 赞助价位与回饋設計
根據不同的贊助價位，提供相應的回饋。請注意，以下價格僅供參考，具體數值需視你的需求而定。
- **低檔**：50 元 / 月（或等值幣別）
    - 回饋：專屬標誌、標誌使用權
- **中檔**：100 元 / 月（或等值幣別）
    - 回饋：贊助者名字加入開源/内容創作名稱、贊助者照片牆
- **高檔**：200 元 / 月（或等值幣別）
    - 回饋：贊助者名字加入開源/内容創作名稱、贊助者名字加入開源/内容創作說明、贊助者名字加入開源/内容创作標誌

## README / 文章 CTA 範本
- **GitHub Sponsors**：
    - 資料夾：README.md
        ```markdown
        # [Open Source/Content Creator] GitHub Sponsors
        ...
        ```
    - 連結：[GitHub Sponsors](https://github.com/sponsors/[你的帳號名稱])
- **Ko-fi**：
    - 資料夾：README.md
        ```markdown
        # [Open Source/Content Creator] Ko-fi
        ...
        ```
    - 連結：[Ko-fi](https://ko-fi.com/[你的帳號名稱])

## Threads 招募贊助貼文
- **GitHub Sponsors**：
    - 貢獻者招募：加入我們的社群，成為 GitHub Sponsors。
    - 連結：[GitHub Sponsors](https://github.com/sponsors/[你的帳號名稱])
- **Ko-fi**：
    - 貢獻者招募：請支持我，讓我能夠持續創作更多內容。
    - 連結：[Ko-fi](https://ko-fi.com/[你的帳號名稱])

---

## 禁止事項
1. 不得使用假數據進行贊助招募。
2. 不得通過買粉的方式獲得贊助。
