### 課程內容：

#### **1. GitHub Sponsors vs Ko-fi：哪個先開？**
- 簡介 GitHub Sponsors 和 Ko-fi 的優缺點
- 根據個人需求和作品特性選擇合適的平台
- 建議在開源/內容創作者平台上選用較為適合的贊助方案

#### **2. 雖然你不是錢大，但定位要高**
- 資料庫：如何透過具體案例說明如何設定個人頁面並進行定位
- 關鍵詞：如何在 GitHub Sponsors 網站上建立個人頁面、如何設計個人頁面以符合創作者的目標與風格

#### **3. 建立三檔贊助價位與回饋**
- 資料庫：具體案例，為你的作品定製三種不同價格的贊助方案
- 關鍵詞：如何設計具有吸引力的贊助價位與回饋內容、如何根據創作者的不同需求調整贊助價位

#### **4. README/文章 CTA 範本**
- 資料庫：具體案例，為你的作品建立吸引人的 README 和文章中的 Call to Action（CTA）
- 關鍵詞：如何設計具有吸引力的 README 和文章 CTA、使用 GitHub Sponsors 的話語術語

#### **5. 募集贊助一則 Threads**
- 資料庫：具體案例，為你的作品建立一個吸引人的 Threads 粉絲專頁
- 關鍵詞：如何透過 Threads 粉絲專頁來招募贊助、使用 GitHub Sponsors 的話語術語

#### **6. 禁止事項（假數據、買粉）**
- 資料庫：具體案例，為你的作品建立一則禁止事項的公告
- 關鍵詞：如何在 GitHub Sponsors 上建立禁止事項公告、避免使用假數據和買粉行為
