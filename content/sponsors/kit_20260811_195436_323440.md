**開源／內容創作者贊助變現包**

### 個人頁定位：
「我是 [您的名字]，是一名熱血的開源與內容創作者，我致力於推動技術發展和分享知識。您的支持將使我能夠繼續這個夢想！」

### GitHub Sponsors 與 Ko-fi 哪個先開？
GitHub Sponsors 是開源項目贊助平台，Ko-fi 則是內容創作者專用的微贊助平台。兩者皆可接受贊助，但 GitHub Sponsors 須針對開源項目進行設定。

### 三檔贊助價位與回饋
| 贊助層級 | 價位 | 回饋 |
| --- | --- | --- |
| **基本** | 5 TWD/月 | 掛名在 README 文件和網站上 |
| **進階** | 20 TWD/月 | 個人頁新增贊助贏家區，掛名在 README 文件和網站上 |
| **VIP** | 50 TWD/月 | 個人頁新增贊助贏家區，掛名在 README 文件和網站上，贊助者將獲得專屬徽章 |

### 禁止事項：
* 不得使用假數據或買粉進行贊助變現包
* 不得違反 GitHub Sponsors 和 Ko-fi 的規定和政策
* 必須遵守開源和內容創作者的倫理準則
