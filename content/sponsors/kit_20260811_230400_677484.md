**開源／內容創作者贊助變現包**

為了讓您的作品更有價值，我們建立了一個贊助變現包，讓您能夠從贊助中獲得收益。下面是如何操作：

1. **GitHub Sponsors vs Ko-fi 哪個先開？**
   GitHub Sponsors 是一個正式的贊助平台，需要您設定基本資料和贊助價位。但是，您也可以使用 Ko-fi 這個更簡單的選擇。Ko-fi 可以直接與 PayPal 或 Stripe 整合，讓您的贊助變得更加方便。

2. **個人頁一句定位**
   您的個人頁面需要有一句清晰明確的定位，告訴訪客什麼樣的內容或服務您提供。這可以幫助吸引更多的支持者和贊助者。

3. **三檔贊助價位與回饋**
   * **基本**: 10 TWD/次
     回饋: 名單中提到您的作品
   * **標準**: 50 TWD/次
     回饋: 提供免費檢查清單和落地／回信大綱
   * **優質**: 100 TWD/次
     回饋: 將 CLI 做成作品集並導流到付費指南

4. **README／文章 CTA 範本**
```
贊助我們：
支持您的內容創作者朋友們的工作吧！

贊助價位：

* 基本 10 TWD/次：名單中提到您的作品
* 標準 50 TWD/次：免費檢查清單和落地／回信大綱
* 優質 100 TWD/次：CLI 作為您的作品集並導流到付費指南

點擊 [贊助](link) 開始您的支持之旅吧！ 
```

5. **Threads 招募贊助貼文**
```
招募贊助：內容創作者變現顧問
尋求贊助您的工作，讓您的作品更有價值！
```

禁止事項：

* **假數據**：請不要提供虛假的訪客流量或贊助收入數據。
* **買粉**：請不要購買大量的評分或點擊，以試圖詐取贊助。
