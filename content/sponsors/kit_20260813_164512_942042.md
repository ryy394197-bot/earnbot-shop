**開源內容創作者變現包**

為了讓您的創作更加豐富，我們推出了開源內容創作者變現包，幫助您獲得更好的收入和聲譽。

### 個人頁定位
「我是 [您的名字]，一名熱愛分享知識的開源內容創作者。我的目標是為大家提供有用的資訊和工具，使我們一起進步。」

### GitHub Sponsors 和 Ko-fi 哪個先開？

GitHub Sponsors 在 2019 年推出，而 Ko-fi 則在 2020 年推出。雖然兩者都可以幫助您獲得支持，但 GitHub Sponsors 對於開源專案提供了更多的便利。

### 三檔贊助價位與回饋

我們提供三個不同的贊助價位，讓您可以根據自己的需求選擇：

1. **基本**: 10 TWD/月
	* 回饋：在您的 README 中顯示贊助者的名字
2. **高級**: 50 TWD/月
	* 回饋：在您的 README 中顯示贊助者的名字，並提供額外的免費檢查清單
3. **企業**: 200 TWD/月
	* 回饋：在您的 README 中顯示贊助者的名字，提供免費檢查清單和個性化的社群發文稿

### README／文章 CTA 範本

您可以使用以下範本來邀請支持：

「感謝您對我的開源專案的支持！如果您願意幫助我繼續創作，請考慮贊助我。您的支持將使我能夠更好地為大家提供有用的資訊和工具。」

### Threads 招募贊助貼文

「想幫助我繼續創作嗎？您可以在 GitHub Sponsors 或 Ko-fi 上贊助我，讓我們一起進步！感謝您的支持！」
