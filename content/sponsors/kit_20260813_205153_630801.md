### GitHub Sponsors vs Ko-fi 哪個先開？
GitHub Sponsors 是由 GitHub 直接提供的贊助平台，而 Ko-fi 則是第三方服務。一般而言，GitHub Sponsors 的使用體驗更好，因為它直接與 GitHub 整合，可以更方便地管理贊助和回饋。但是，Ko-fi 也有其優點，如更豐富的功能和個人化選項。
