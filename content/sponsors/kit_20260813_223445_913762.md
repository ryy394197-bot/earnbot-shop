**開源內容創作者贊助變現包**

### 個人頁定位
您的支持是我們能夠持續創作的動力。透過這個贊助變現包，讓我們一起攜手將優質內容帶給更多人。

### GitHub Sponsors vs. Ko-fi 哪一個先開？
GitHub Sponsors 和 Ko-fi 都是優秀的選擇，但如果您是一位剛入門的開源作者，我建議先使用 GitHub Sponsors。因為 GitHub Sponsors 提供了更完善的管理工具和分析功能，幫助您更好地跟踪贊助情況。

### 三檔贊助價位與回饋
我們提供三種不同的贊助價位，讓您可以根據自己的喜好和預算選擇：

* **金牌贊助者**：每月贊助 10 TWD，可獲得專屬的 README 設計師體驗，且將在個人頁顯示您的贊助 logo。
* **銀牌贊助者**：每月贊助 5 TWD，可獲得專屬的 README 設計師體驗，以及在贊助者名單中顯示您的名字和 logo。
* **銅牌贊助者**：每月贊助 1 TWD，可獲得專屬的 README 設計師體驗，並且將在贊助者名單中顯示您的名字。
