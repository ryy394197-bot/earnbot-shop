**開源／內容創作者贊助變現包**

GitHub Sponsors 與 Ko-fi 皆可使用，個人頁一句定位：「支持我創作更多優質內容！」

## 三檔贊助價位與回饋

| 贊助層級 | 回饋內容 |
| --- | --- |
| **星光** (100 TWD) | 個人封面圖片、專屬贊助者名單 |
| **月亮** (500 TWD) | 優先發文權限、贊助者名義合作文章 |
| **太陽** (2,000 TWD) | 專項內容創作服務（需討論內容） |

## README／文章 CTA 範本

你可以在 README 或文章中添加以下 CTA：

「支持我的工作，讓我繼續為你們提供高品質內容！贊助變現包：https://link.to/your.sponsor.page“

## Threads 招募贊助貼文

「需要支持創作者嗎？我們正在尋找贊助者來幫助我們繼續創作！https://link.to/your.sponsor.page」

### 禁止事項
* 請勿使用假數據或隱瞞真實情況。
* 請勿購買粉絲或假帳戶進行贊助。
