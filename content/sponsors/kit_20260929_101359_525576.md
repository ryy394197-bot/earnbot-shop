開源／內容創作者贊助變現包

### 說明
本套包裝包含個人頁一句定位、三檔贊助價位與回饋（勿保證收入）、README及文章 CTA 範本、一則招募贊助的短貼，並附上禁止事項說明。系統會將相關內容推上 GitHub earnbot-shop；Ko-fi 亦為選用。

### 包裝內容

1. **個人頁一句定位**
   - 定位文案：請提供一個簡潔明確的個人頁定位文案。
   - 說明：這有助於提升你的個人品牌，讓潛在贊助者清晰了解你的價值觀和目標。

2. **三檔贊助價位與回饋**
   - **第一檔：$100**  
     回饋：提供一個感謝信及一個獨家優惠碼。
   - **第二檔：$500**  
     回饋：除上述外，還會獲得一張個人照片的使用許可權，以及一個專屬標籤位。
   - **第三檔：$1,000**  
     回饋：除了以上回饋外，你將獲得一個獨家訪談機會，並在你的文章或社群媒體上展示贊助者的標誌。

3. **README及文章 CTA 範本**
   - README 文檔：提供一個簡單易懂的 README 文件範例，用於分享贊助者如何使用平台進行贊助。
   - CTA 範本：設計好的 CTA（Call to Action）標籤，方便你在個人頁、文章或社群媒體上吸引潛在贊助者的注意。

4. **招募贊助的短貼**
   - 短貼文案示例：「歡迎贊助我的內容創作！每筆贊助都將幫助我持續創作更多有價值的內容。請點擊下方連結進行贊助，一起支持我！」
   - 說明：透過招募贊助的方式吸引潛在贊助者。

5. **禁止事項**
   - 禁止使用假數據或購買粉絲。
   - 禁止出售贊助回饋，如優惠碼、訪談機會等。
   - 禁止任何可能影響平台使用者體驗的行為。

### 使用說明
1. 安裝 earnbot-shop：請前往 GitHub earnbot-shop 下載並安裝該套件。若未使用 GitHub，則可選用 Ko-fi 作為替代方案。
2. 根據提供的範例進行修改和填充。
3. 將所有內容貼上你的個人頁、文章或社群媒體上。

### 注意事項
- 勿保證收入：請明確告知潛在贊助者，平台的收益無法保障。
- 請遵守禁止事項：確保不會違背平台規定及使用協議。

### 系統整合建議
1. **GitHub earnbot-shop**：將相關內容推上 GitHub earnbot-shop。
2. **Ko-fi 作為選用**：若無 GitHub 帳號，可考慮在 Ko-fi 上設立贊助頁面。請注意，Ko-fi 的使用條款和 earnbot-shop 不完全相同。
