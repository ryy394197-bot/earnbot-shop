### 1. 創作者定位與價位設定

#### 定位
請填寫一句簡短而有力的創作者定位，以吸引對你內容有興趣的贊助者。

#### 贊助價位
| 貼圖數 | 短片數 | 月金額 |
|--------|--------|--------|
| A      | B      | $50    |
| C      | D      | $100   |
| E      | F      | $200   |

*請根據自身內容和平台特性調整以上價位。*

### 3. README／文章 CTA 範本

#### 貼圖招募
請填寫一段吸引人的貼圖招募文案，並附上連結至 GitHub earnbot-shop。

**示例：**
> **歡迎贊助我的創作！**
>
> 我的內容為您帶來了無數的喜悅和啟發，希望您能成為我的長期支持者。請關注我的官方帳號並點擊下方連結進行贊助。
>
> [點此贊助](https://github.com/yourusername/earnbot-shop)

#### 文章 CTA 篇
**示例：**
> **感謝您的閱讀！**
>
> 您的每一分支持都極其珍貴，讓我們能夠持續創作更多令您喜愛的作品。請通過下方連結贊助我的內容。
>
> [點此贊助](https://github.com/yourusername/earnbot-shop)

### 5. 禁止事項說明

#### 禁止行為
- **假數據**：請勿提交虛構的贊助數量和詳情。
- **買粉**：請勿購買或招募虚假的贊助者。

### 6. GitHub earnbot-shop 部署

1. 開啟你的 GitHub 複本，並在 repo 的 `FUNDING.yml` 中填入創作者定位、價位設定及回饋設計。
2. 對應地在 README 或文章中插入 CTA 範本連結。
3. 啟用 earnbot-shop：前往 https://github.com/apps/earnbot-shop，選擇你的 repo 並啟用。

### 7. Ko-fi 為選用方案

若無 KF 設定，請考慮使用 Patreon 作為替代方案。Patreon 提供了類似的贊助平台功能，但需自行設定和維護。
