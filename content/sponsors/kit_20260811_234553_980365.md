**開源內容創作者贊助變現包**

GitHub Sponsors 和 Ko-fi 兩個平台都提供了免費的支持和贊助功能，但 GitHub Sponsors 將於 2023 年 6 月 1 日正式啟動。因此，我們將首先嘗試使用 Ko-fi。

**個人頁一句定位**
"作為一個致力於開源的內容創作者，我們需要您的支持來繼續推進我們的工作。您的贊助將幫助我們製作更好的內容，並且讓我們可以繼續做我們最愛的事情——分享知識和激勵他人!"

**三檔贊助價位與回饋**

| 贊助價位 | 回饋 |
| --- | --- |
| Basic ($5) | 個人頁的贊助者名單中顯示您的名字 |
| Premium ($10) | 以上權益，另外獲得免費的內容下載和專用 Discord 頻道 |
| VIP (自定價) | 以上權益，另外獲得專人幫助、優先回答問題以及特權會員名義 |

**README／文章 CTA 範本**
"您想支持我們的工作嗎？加入我們的贊助計劃吧！[點擊連結加入 Ko-fi 贊助](https://ko-fi.com/你的 GitHub ID)"

**Threads 招募贊助貼文**
"呼朋引伴！現在正在招募贊助者！如果您是開源愛好者或內容創作者，歡迎參與我們的工作並提供支持。加入我們的贊助計劃吧！[點擊連結加入 Ko-fi 贊助](https://ko-fi.com/你的 GitHub ID)"

**禁止事項**
請注意以下事項：
* 不得使用假數據或造假來誇大您的贊助量。
* 也不得購買粉絲，以試圖提高您的贊助率。

我們致力於維護開源精神和透明度，因此希望您能夠遵守以上規定。感謝您的支持！
