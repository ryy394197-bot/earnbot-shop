| 合作者 | NT$2000 | 名字出現在專案贊助者列表中，獲得專屬感謝訊息與技術內容更新通知，並參與專案未來版本的意見徵詢。 |

### ❌ 禁止事項（嚴禁觸犯）

- **禁止使用假數據或虛構贊助數字**（如虛構贊助人數、金額等），此行為違反 GitHub 政策與平台規則。
- **禁止買粉或使用機器人帳號進行贊助**，此行為將導致帳號受限與專案信用受損。
- **不得隱藏贊助者資訊**，贊助者名單需公開透明，符合 GitHub 的 FUNDING.yml 規範。
- **不得以贊助為名進行不實宣傳或詐騙行為**，此行為將導致專案被封鎖與個人帳號處罰。
