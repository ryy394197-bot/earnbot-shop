**開源／內容創作者贊助變現包**

**定位**: 我是自由開源的 [你的名字]，致力於發展獨立且高品質的軟體與資訊。透過這個贊助變現包，我希望能夠與您一起分享我的創作，並讓我們共同締造出更美好的未來。

**贊助價位**

* **捐贈者**: NT$ 100
	+ 名單內加入您的名字或組織名稱
	+ 在README中顯示贊助者的列表
* **伙伴**: NT$ 500
	+ 名單內加入您的名字或組織名稱
	+ 在README中顯示贊助者的列表
	+ 可以在GitHub Sponsors上獲得專屬徽章
* **支持者**: NT$ 1,000
	+ 名單內加入您的名字或組織名稱
	+ 在README中顯示贊助者的列表
	+ 可以在GitHub Sponsors上獲得專屬徽章
	+ 將會獲得提前存取新功能和特定內容

**回饋**
* 我將會持續創作並分享我的知識與經驗。
* 我將會持續更新和改善我的軟體與資訊。
* 您的贊助將幫助我繼續發展高品質的內容。

**GitHub Sponsors vs. Ko-fi**
首先，我們在 GitHub Sponsors 上建立了贊助變現包，然後才是 Ko-fi。這樣做的原因是，因為 GitHub Sponsors 的流量和認可度較高，因此能夠吸引更多的贊助者。

**README／文章 CTA 範本**
你可以在你的 README 或文章中加入以下 CTA：
```
如果您喜歡我的內容，請考慮贊助我。
透過 GitHub Sponsors 您可以贊助我的軟體與資訊。
[GitHub Sponsors 按鈕]
```

**Threads 招募贊助貼文**
你也可以在 Threads 上分享以下的招募贊助貼文：
```
招募贊助者
如果您喜歡我的內容，請考慮贊助我。
透過 GitHub Sponsors 您可以贊助我的軟體與資訊。
[GitHub Sponsors 按鈕]
```

**禁止事項**
* 假數據：不得使用假的贊助者名單或贊助金額。
* 買粉：不得購買虛假的贊助者或流量。
* 其他違規行為：不得進行任何可能損害我的聲譽或影響我贊助變現包正確性的行為。
