### 個人頁定位

### GitHub Sponsors vs Ko-fi 哪個先開？
Ko-fi 先開源於 2014 年，而 GitHub Sponsors 則是在 2020 年推出。由於 GitHub 的廣泛使用和社區影響力，我們推薦使用 GitHub Sponsors。

### 三檔贊助價位與回饋

| 贊助層級 | 每月貢獻額度 |
| --- | --- |
| **Bronze** | NT$100 |
| **Silver** | NT$500 |
| **Gold** | NT$2,000 |

回饋：
* Bronze：專屬 Discord 伺服器加入權限
* Silver：名列贊助者名單，並獲得每月專屬內容預覽
* Gold：與作者進行線上分享會，且獲得 VIP 版專屬內容
