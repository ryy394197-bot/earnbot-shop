## GitHub Sponsors 與 Ko-fi 哪個先開？
首先，我們需要在 GitHub Sponsors 和 Ko-fi 這兩個平台上開通贊助帳戶。GitHub Sponsors 是由 GitHub 提供的官方贊助平台，而 Ko-fi 則是另一個著名的支持創作者的網站。

## 三檔贊助價位與回饋
我們將提供三種不同的贊助價位，並根據贊助者的捐款數額提供相應的回饋：

* **小星星**：捐款 10 TWD，贈送免費檢查清單和落地／回信大綱
* **大星星**：捐款 50 TWD，獲得專屬內容創作者贊助變現包
* **超級星星**：捐款 100 TWD，獲得一對一的內容創作者合作和支援
