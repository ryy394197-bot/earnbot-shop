《開源/內容創作者贊助變現包》

---

### 一、GitHub Sponsors 與 Ko-fi 員工選擇
在開始打造你的開源或內容創作者品牌時，如何選擇適合的贊助平台是一個重要的決定。我們建議首先考慮 GitHub Sponsors。以下為理由：

1. **長期穩定收入**：與 Ko-fi 不同，GitHub Sponsors 會自動扣款，不會因為用戶取消訂閱而停止收款。
2. **社群影響力**：GitHub 是全球最大的開源技術平台，Sponsor 收費後，你的名字將被列為官方支持者，影響力遠大於個人網站的 Kofi。
3. **透明度與公平性**：GitHub Sponsors 的評分系統會根據用戶對你的項目和 GitHub 贊助計劃的支持程度進行評估，確保收入分配的公正。

### 二、個人頁一句定位
在為你的開源/內容創作者品牌建立個人頁時，第一句話應該明確地展示你所追求的核心價值。例如：

- **「我們堅持用技術改變世界」**
- **「讓每一個人都能享受科技帶來的便利」**

### 三、三檔贊助價位與回饋
在設定三個不同的贊助價位時，請確保這些價格能夠覆蓋不同用戶的需求和期望。以下是一個範例：

1. **標準版（每月 $5）**
   - 回饋：專屬標籤、GitHub 贊助者認證、優先支援。
2. **精選版（每月 $10）**
   - 回饋：官方社群貼文推薦、GitHub 標誌使用權、優質內容預覽權。
3. **尊享版（每月 $20）**
   - 回饋：個人專屬標籤、特製感謝信、長期合作機會。

### 四、README/文章 CTA 範本
在 README 文件或相關文章中，請使用以下 CTA 語言吸引用戶贊助：

- **「加入我們的開源社群，成為 GitHub Sponsors 支持者！」**
- **「點擊贊助金額，開始你的支持之旅！」**

### 五、一則 Threads 招募贊助貼文
在推特（Threads）上發布招募贊助的帖子，可以有效提升曝光率和用戶參與度：

- **標題**：【招募】加入我們的開源社群！成為 GitHub Sponsors 支持者
- **內容**：
  - 簡短介紹你的品牌及目標。
  - 詳細說明贊助價位與回饋。
  - 呼吁用戶點擊 CTA 按鈕，開始支持。

### 六、禁止事項（假數據、買粉）
在建立社群時，請確保遵守以下規範：

- **不要使用假數據**：保持真實的贊助數量和評價。
- **避免買粉**：請用戶實際體驗你的產品或內容再考慮贊助。
