**個人頁一句定位**
- 你希望你的個人頁面呈現出怎樣的定位？請填入以下文字，作為你個人頁面的一句定位。
- **範例：**「我是一個熱愛分享設計知識與技巧的人，希望能透過我的分享幫助更多人。」

**三檔贊助價位與回饋**
- 該價位僅做為參考，請根據你的實際需求和資源進行調整。以下示範了三種不同的贊助價位及其對應的回饋內容。
- **第一級：$50/月**
  - 回饋：在個人頁面展示贊助者的頭像與簡短介紹；每月一次更新的感謝信；邀請參與專案討論或合作機會。
- **第二級：$100/月**
  - 回饋：除了第一級回饋外，還可獲得：
    - 每月一次的個人訪談機會；
    - 詳細的贊助者報告，包括捐款對內容創作的影響、未來計畫等。
- **第三級：$200/月**
  - 回饋：除了第二級回饋外，還可獲得：
    - 每季度一次的專屬訪談機會；
    - 詳細的贊助者報告（內容同第二級）；

**README／文章 CTA 範本**
- 以下是一個簡單的文章 CTA 篇樣式範例，請根據你的需要進行修改。
- **範例：**
  >「你是否也想為自己喜歡的內容創作者贊助？現在就有機會獲得更多回饋！點擊下方連結了解詳情：[贊助我的文章](https://example.com/support-article)。」

**一則短貼招募贊助**
- **範例：**
  >「感謝您對我們的支持！為了讓更多人看到您的贊助，我們希望您可以分享這張照片給你的社群好友們。請按以下連結下載照片：[下載照片](https://example.com/download-photo)」

**禁止事項（假數據、買粉）**
- **不得使用假數據進行贊助行為，或在內容中植入廣告以吸引非 genuine 貼文的關注。
- **不得採取任何手段購買粉絲或其他虛假數據，維護贊助生態圈的健康與公平。**

### 系統說明
- **GitHub earnbot-shop**：系統會將 FUNDING.yml 及 CTA 推上 GitHub earnbot-shop，方便你進行內容創作者的贊助變現。
- **Ko-fi 為選用**：若需要使用 Ko-fi 作為贊助平台，請自行在 GitHub 上申請並配置。


### 注意事項
- 貼文與短貼都需符合相關規定，不得違反任何社群規範或法律法規。
