**開源內容創作者贊助變現包**

**GitHub Sponsors vs Ko-fi 哪個先開？**
GitHub Sponsors 由 GitHub 自身推出，提供給開源專案維護者和貢獻者的支持平台。Ko-fi 則是一個更早成立的平台，允許創作者設置贊助價位，並提供簡單易用的工具。

**個人頁一句定位**
我是 [Your Name]，一個致力於開源內容創作的熱情份子。我們希望透過 GitHub Sponsors 和 Ko-fi，得到你的支持和鼓勵。

**三檔贊助價位與回饋**
我們設置了三個不同價位的贊助方案，每一層都帶來不同的回饋和優惠：

1. **貢獻者**：$5/月，獲得專屬名單文案，以及我的最新文章免費共享。
2. **支持者**：$20/月，除了貢獻者的回饋外，还包括私人 Discord 會議室一次。
3. **夥伴**：$50/月，除了上述回饋外，还包括一個線下活動的參與機會，以及我的專屬名片設計。

請注意，這些價位和回饋是暫時的設定，我們將根據你的反饋進行調整。

**README／文章 CTA 範本**
你可以使用以下範本在 README 或文章中呼喚贊助：
```
### 支持我們

感謝你對我們作品的喜愛！如果你覺得這個專案或文章有用，歡迎透過 GitHub Sponsors 或 Ko-fi 支援我們。

[GitHub Sponsors](https://github.com/sponsors/your-github-username)
[Ko-fi](https://ko-fi.com/your-kofi-handle)
```
**Threads 招募贊助貼文**
你可以在 Threads 上分享如下內容：
```
🚀 我們需要你的支持！ 🚀

你喜歡我們的開源專案和文章嗎？那就來支持我們吧！ 🤩

透過 GitHub Sponsors 或 Ko-fi，幫助我們繼續創作和更新。 ✨

[GitHub Sponsors](https://github.com/sponsors/your-github-username)
[Ko-fi](https://ko-fi.com/your-kofi-handle)
```
**禁止事項**

* 請不要使用假數據或虛假的贊助來試圖欺詐我們。
* 不要購買粉絲或假的贊助，以試圖提高你的影響力。

我們期盼著你的支持和鼓勵！
