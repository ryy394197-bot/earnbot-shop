# 开源/内容创作者赞助变现包

## GitHub Sponsors 與 Ko-fi 員先開啟
根據目前的市場情況，建議您先啟用 GitHub Sponsors。GitHub Sponsors 是一個免費且功能完善的贊助系統，適合小眾或個人創作者使用。

### 一則 Threads 招募贊助貼文範本：
```
🌟 新聞稿 🌟
來源: [您的GitHub專案名稱](https://github.com/您的GitHub專案名稱)
歡迎各位支持者加入我的社群，成為 GitHub Sponsors 貨幣化計劃的一員！
- 🔗 了解詳情：[GitHub Sponsors](https://github.com/sponsors/您的GitHub專案名稱)
- 📦 資助不同級別：
  - 基本級：$10 / month
  - 普通級：$25 / month
  - 專業級：$50 / month

請大家幫忙推廣，讓更多人知道我們的專案並支持我！謝謝大家！

[您的GitHub專案名稱] | [您的GitHub專案連結]
```

## 個人頁一句定位
在個人頁上，您應該明確地說明自己是個創作者或開發者，並且清楚表達對 GitHub Sponsors 的支持。例如：
```
我是 [您的名字]，一名熱愛程式設計的自由工作者。
非常感謝大家的支持！請考慮成為我的 GitHub Sponsors 貨幣化計劃的一員，讓我們一起努力把專案做到更好！
```

## 三檔贊助價位與回饋
### 基本級：$10 / month（每月 $120）
- 回饋：加入專案的技術社群，得到早期預覽版和新功能。
- 註：此回饋可能依專案需求有所不同。

### 普通級：$25 / month（每月 $300）
- 回饋：加入專案的技術社群、獲得早期預覽版和新功能，以及一次免費的邀請函參與專案活動。
- 註：此回饋可能依專案需求有所不同。

### 專業級：$50 / month（每月 $600）
- 回饋：加入專案的技術社群、獲得早期預覽版和新功能，一次免費邀請函參與專案活動以及與創作者進行一對一諮詢。
- 註：此回饋可能依專案需求有所不同。

## 禁止事項
- **假數據**：禁止使用虛構的贊助回饋或數據。
- **買粉**：請不要購買贊助者，這會影響社群環境和專案品質。
