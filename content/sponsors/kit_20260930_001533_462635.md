《開源/內容創作者贊助變現包》

本套包裝旨在幫助個人或小型團隊打造一個有效的贊助變現方案，讓您能輕鬆吸引志同道合的支持者並獲得必要的回饋與資源支持。

### 包含項目
1. **個人頁一句定位**：精確地定義您的品牌和價值觀，以吸引正確的贊助者。
2. **三檔贊助價位與回饋**：
   - **基本版（$50）**：免費加入社群、首次合作機會等。
   - **優質版（$100）**：邀請函、獨家內容分享、定期更新通知等。
   - **尊貴版（$200）**：專屬邀請函、個人化感謝信、長期合作機會等。
3. **README／文章 CTA 範本**：建立一個專業且有吸引力的宣傳頁面，吸引訪客點閱更多資訊。
4. **一則短貼招募贊助**：透過簡短文案邀請潛在支持者加入您的贊助行列。
5. **禁止事項（假數據、買粉）**：確保所有贊助回饋都是真實有效且不含任何商業詐騙行為。

### 系統說明
- **FUNDING.yml／CTA 推上 GitHub earnbot-shop**：系統會自動將您的 FUNDING.yml 和 CTA 論文推送到 GitHub earnbot-shop，方便您進行後續的管理與更新。
- **Ko-fi 為選用**：此套包裝為 Ko-fi 服務提供簡易設置指南，但若您有其他偏好（例如 Patreon、GoCardless 等），請聯繫我們以取得定制化建議。

### 使用說明
1. 完成上述各項設定後，您即可開始吸引贊助者並獲得所需的回饋與資源支持。
2. 實際操作中，請確保每種贊助價位的回饋內容真實有效且具體實質。
3. 遵守「禁止事項」規定，避免任何可能損害您品牌形象或利益的情況發生。

### 注意事項
- **免費試用**：本套包裝提供 14 天免費試用期，期間內無費用負擔。
- **聯繫我們**：如果您有任何疑問或需要更多幫助，請隨時與我們聯絡，我們將竭誠為您服務。
