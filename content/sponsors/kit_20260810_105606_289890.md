**內容創作者贊助變現包**

### 個人頁定位
「透過您的支持，讓我能夠持續創造有價值的內容！」

### GitHub Sponsors vs. Ko-fi
GitHub Sponsors 先開源並推出贊助功能，而 Ko-fi 則是更加早期與簡單的平台，提供一種直接的支援作者的手段。若您希望在 GitHub 上建立您的贊助計畫，我建議先試用 GitHub Sponsors。

### 三檔贊助價位
| 類型 | 價值 | 回饋 |
| --- | --- | --- |
| 基本 | $5/月 | 個人署名、免費內容升級 |
| 中等 | $10/月 | 上述之外，另外附送專屬 Discord 色塊 |
| 高級 | $20/月 | 上述之外，另外附送專用 GitHub Sponsors 頁面 |

### README / 文章 CTA 範本
```markdown
贊助我的專案 [GitHub Sponsors](https://github.com/sponsors/your-username) 或 [Ko-fi](https://ko-fi.com/your-kofi-handle)
```
### Threads 招募贊助貼文範本
「想支持我的創作嗎？加入我的 GitHub Sponsors 或 Ko-fi 並幫助我持續創造有價值的內容！每一份支持都將是我繼續努力的動力！ [連結至 GitHub Sponsors 或 Ko-fi] """

### 禁止事項
- **不得假數據**：任何使用虛構或不準確的贊助數據，可能會導致嚴重後果。
- **不得買粉**：購買僞造粉絲帳戶來抬高贊助人數，這種行為違反了平台政策，並且可能會造成法律問題。

### 注意事項
本贊助變現包的內容僅供參考，實際執行時請務必遵守每個平台的條款和政策，並確保您的活動符合法律要求。
