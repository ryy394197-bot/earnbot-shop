開源／內容創作者贊助變現包，包含 GitHub Sponsors 與 Ko-fi 的策略建議與工具整合方案。本計畫適用於希望透過社群支持維繫創作並進行長期發展的個人或團隊。

### 一、GitHub Sponsors 與 Ko-fi 哪個先開？
- **GitHub Sponsors**：優點在於直接連結到 GitHub 財務系統，方便管理贊助者資訊與自動化回饋機制。若希望長期維持社群互動，且有計畫透過 GitHub 進行技術分享或合作，則建議先行啟用。
- **Ko-fi**：適合短期內快速獲得資金支援，特別是對於即將舉辦活動、購買創作工具等用途較為合適。此外，Ko-fi 的界面友好，能夠直接收到捐款，且支持多國貨幣。

### 二、個人頁一句定位
1. **GitHub Sponsors**: 建立一個專屬的 GitHub 財務頁面，清晰標示贊助者名單及回饋機制。建議使用「Sponsor」按鈕或連結，以鼓勵更多人加入。
2. **Ko-fi**: 在 Ko-fi 頁面上設定簡短且有吸引力的介紹文字，並強調長期支持對創作者的重要性。

### 三、三檔贊助價位與回饋
1. **$20 贊助**
   - 回饋：感謝信一封，GitHub Sponsors 簽名版權文獻一份。
2. **$50 贊助**
   - 回饋：感謝信一封，GitHub Sponsors 簽名版權文獻一份，以及個人專屬的 GitHub 代碼片段。
3. **$100 贊助**
   - 回饋：感謝信一封，GitHub Sponsors 簽名版權文獻一份，個人專屬的 GitHub 代碼片段，並可獲得一次免費技術諮詢。

### 禁止事項
1. **假數據**：避免使用虛構或不實的贊助數字。
2. **買粉**：確保所有贊助者都是真實存在的用戶。
