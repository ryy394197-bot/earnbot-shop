|---------|------|

| **精英版** | 提供所有內容創作者所需之服務，包括個人頁一句定位、Ko-fi 等社群回饋及一則短貼招募贊助，另可申請合作機會與資源支持。 |

## 三、README / 文章 CTA範本
- **CTA範本**：包含具體的行動邀請語句，鼓勵讀者進行贊助。
- **Markdown 樣式示例**：
```
## 資助我們！成為我們的支持者

### 基本版
贊助 $100 以上即可獲得個人頁一句定位及 Kofi 社群回饋。

### 优先版
贊助 $200 以上，除了基本版所有福利外，還會得到一則短貼招募贊助。

### 精英版
贊助 $500 以上，將獲得所有內容創作者所需之服務，包括個人頁一句定位、Kofi 社群回饋及一則短貼招募贊助，並可申請更多合作機會與資源支持。
```

## 四、招募赞助短帖
- **範例**：請撰寫簡短的短帖邀請讀者進行贊助，例如：“加入我們的社群，一起成長！成為我們的支持者，讓你的名字和標誌展示在個人頁上。贊助 $500 以上，還會得到一則短貼招募贊助。”

## 五、禁止事項
1. **假數據**：請勿提供虛假的贊助回饋。
2. **買粉**：請勿進行任何與贊助相關的買粉行為。

## 六、說明
- **GitHub earnbot-shop**：系統會把 FUNDING.yml／CTA 推上 GitHub earnbot-shop，讓讀者能直接在平台上進行贊助。
- **Ko-fi 為選用**：若需使用 Ko-fi 作為贊助平台，請注意其收費模式及相關規定。

此開源內容創作者包旨在為個人或小型團隊提供一個簡單易用的贊助变现工具。透過系統化的設計與範本，協助你快速建立起自己的社群支持者基礎。請務必遵守禁止事項以維護平台正義及公平性。
