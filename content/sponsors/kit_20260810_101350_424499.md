### GitHub Sponsors 與 Ko-fi 哪個先開？

首先，我建議使用 GitHub Sponsors。因為它是 Git Hub 官方的贊助平台，使用者可以直接在 GitHub 上發起贊助，且有更好的管理工具。

但如果你想要多樣化您的贊助渠道，也可以考慮使用 Ko-fi。它是一個開源、可自定制的贊助平台，可以與 GitHub Sponsors 整合。

### 三檔贊助價位與回饋：

1. **基本版**：每月贊助 10 TWD，獲得專屬名單文案和線上直播優先入口。

3. **鉅款版**：每月贊助 100 TWD，獲得上述內容，並可獲得一次免費專案合作機會。
