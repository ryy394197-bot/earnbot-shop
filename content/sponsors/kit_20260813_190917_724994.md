**開源內容創作者贊助變現包**

### 個人頁定位
透過這個贊助變現包，我們誠摯邀請您支持我們的開源內容創作之旅。您的贊助將成為我們繼續創作和分享知識的重要動力。

### GitHub Sponsors vs Ko-fi 哪個先開
我們選擇使用 GitHub Sponsors 作為首選平台，因為它提供了更好的管理工具和回饋機制。但是，我們也會在 Ko-fi 上建立帳戶，以便您可以通過多種方式支持我們。

### 三檔贊助價位與回饋

| 價位 | 回饋 |
| --- | --- |
| $5 | 個人感謝留言和贊助者名單上顯示您的名字 |
| $10 | 個人感謝留言、贊助者名單上顯示您的名字，以及在最新文章中提及您 |
| $20 | 個人感謝留言、贊助者名單上顯示您的名字、在最新文章中提及您，並且獲得私人 Discord 頻道訪問權 |

### README／文章 CTA 範本
您可以將以下內容添加到您的 README 或文章中，以方便讀者贊助您：

"如果您喜歡這篇文章或我的開源專案，請考慮支持我通過 GitHub Sponsors 或 Ko-fi。您的贊助將有助於我繼續創作和分享知識。"

### Threads 招募贊助貼文
"呼籲！我們正在尋找對內容創作者的支持者！如果您喜歡這篇文章或我的開源專案，請考慮通過 GitHub Sponsors 或 Ko-fi 來贊助我。您的支持將有助於我繼續創作和分享知識。"

### 禁止事項
請注意以下事項：

* 不得使用假數據或購買粉絲來操弄贊助數量。
* 不得通過任何方式購買贊助或僱傭人來增加贊助數量。
