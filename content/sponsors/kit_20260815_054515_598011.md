# 開源/內容創作者贊助變現包

## GitHub Sponsors 與 Ko-fi
### 建議開：GitHub Sponsors
1. **優點**：
   - 用戶數量較多，品牌影響力強。
   - 支援 GitHub Actions、Issues 及 Pull Request 等功能。
2. **缺點**：
   - 需要額外維護與管理。

### 建議開：Ko-fi
1. **優點**：
   - 赞助者可直接購買商品，提高互動性。
   - 可自訂回饋內容，如專屬貼文、Q&A 等。
2. **缺點**：
   - 權限較少，無法支援 GitHub Actions。

## 個人頁一句定位

「加入我的贊助行列，支持我的作品和創作。您的支持將是我前行的動力！」

## 贊助價位與回饋
### 三檔贊助價位及回饋
1. **基本級**（$5 / 月）
   - 回饋：專屬標籤、贊助者列名。
2. **進階級**（$10 / 月）
   - 回饋：專屬標籤、贊助者列名 + 精選內容或 exclusive 項目。
3. **尊榮級**（$25 / 月）
   - 回饋：專屬標籤、贊助者列名 + 精選內容或 exclusive 項目 + 特別 Q&A。
