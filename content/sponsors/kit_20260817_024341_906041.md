# 開源/內容創作者贊助變現包
## GitHub Sponsors 與 Ko-fi 員工開設建議

### 什麼時候先開？
- **GitHub Sponsors**：一般建議在開始開發產品或服務前，先建立一個穩定的收入來源。若已有一定的社群認同度和用戶基礎，再考慮啟動 GitHub Sponsors。
- **Ko-fi 員工**：較適合剛起步的新創團隊，可以快速獲得現金回饋，並吸引有興趣支持你的觀眾。

### 一個個人頁的定位
- **GitHub Sponsors**：提供詳細的技術介紹與進展，讓贊助者了解開發者的專業背景和工作流程。
- **Ko-fi 員工**：透過故事性內容（如開發歷程、遇到的挑戰等）建立情感聯繫。

### 三檔贊助價位與回饋
#### GitHub Sponsors
1. **Basic**：$5/月
   - 回饋：小額的技術協助，優先處理問題。
2. **Pro**：$20/月
   - 回饋：每月一個技術報告，加入開發者社群交流。
3. **Enterprise**：$100/月及以上
   - 回饋：專屬版權、獨家內容、優先參與測試。

#### Ko-fi 員工
1. **Bronze**：$5/次
   - 回饋：小額捐款感謝，不提供其他回饋。
2. **Silver**：$20/次
   - 回饋：每月一次的技術分享會或專題討論。
3. **Gold**：$100/次及以上
   - 回饋：獨家合作機會、參與產品設計等。
