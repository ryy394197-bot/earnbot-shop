### GitHub Sponsors 與 Ko-fi 哪個先開?
GitHub Sponsors 在 2021 年正式推出，為開源貢獻者提供一個平台來接收贊助。Ko-fi 則是早於 GitHub Sponsors 的一個社交媒體平台，讓用戶可以通過小額捐款支持內容創作者。

### 三檔贊助價位與回饋
| 贊助等級 | 價值 | 回饋 |
| --- | --- | --- |
| 小星光 | 10 TWD/月 | 個人頁專屬名片、一次免費檢查清單 |
| 大星光 | 50 TWD/月 | 小星光回饋 + 一次免費落地／回信大綱 |
