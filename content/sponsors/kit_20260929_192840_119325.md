開源／內容創作者贊助變現包

## 介紹
本套工具提供一個完整的開源或內容創作者贊助變現方案，包含個人頁一句定位、三檔贊助價位與回饋、README文章 CTA範本、一則招募贊助短貼、禁止事項等。系統會自動將FUNDING.yml和CTA推上GitHub earnbot-shop；Ko-fi為選用。

## 關鍵特性
- **個人頁一句定位**：精確定義你的品牌或內容特色，讓贊助者更容易理解。
- **三檔贊助價位與回饋**：提供不同金額的贊助方案，滿足廣泛的需求。
- **README文章 CTA範本**：自動化生成吸引人的CTA（Call to Action）範本，提高贊助邀請的效果。
- **一則招募贊助短貼**：設計一個有吸引力的招募短貼，用來吸引新的贊助者。
- **禁止事項**：明確列出禁止行為，確保贊助過程透明且公平。

## 使用範例
### 1. 個人頁一句定位
```markdown
# 我的名字 - 網站名稱

我是一位熱愛科技的內容創作者，專注於分享最新的程式語言、軟體開發技巧與資訊安全知識。我的目標是幫助讀者提升技術實力，並建立一個友善且開放的社群。

- **定位**：專業、創新、樂觀
```

### 2. 資料夾結構
```
.
├── CTA.md
├── README.md
├── FUNDING.yml
└── short-post.png
```

### 3. README文章 CTA範本
```markdown
# 我的名字 - 網站名稱

歡迎贊助我的內容創作！您的支持將為我提供更多資源，讓我能持續分享更多有價值的資訊。以下是三種不同的贊助價位與回饋：

## 一級贊助（$10/月）
- 贈送 exclusive 電子書
- 總共 $20

## 二級贊助（$25/月）
- 購買一次專業技術課程
- 總共 $40

## 三級贊助（$100/月）
- 成為品牌合作夥伴，獲得獨家優惠與曝光機會
- 總共 $200

請點擊下方連結進行贊助：
[加入我的支持者](https://github.com/kofi)
```

## 注意事項
- **禁止事項**：切勿使用假數據或購買粉絲。請確保所有信息都是真實和合規的。

### 具體範例
若您決定使用Ko-fi，請按照以下步驟操作：
1. 創建一個Ko-fi帳戶。
2. 將你的GitHub專案連結到Ko-fi。
3. 在Ko-fi上設置贊助價位與回饋。
