### GitHub Sponsors VS Ko-fi 哪個先開?

GitHub Sponsors 在 2019 年推出，Ko-fi 則在 2014 年推出。雖然 GitHub Sponsors 的早期版本有點延遲，但現在它已經是業界領先者之一。

### 個人頁一句定位

* "為您帶來創意內容的開源作者，我們一起變現吧！"
* "探索新知識、體驗優質內容，支持我們的創作之路！"

### 三檔贊助價位與回饋

| 贊助價位 | 回饋 |
| --- | --- |
| **小星星** ($1-$5) | 獲得內容作者署名、免費升級專案、特殊贈品或體驗 |
| **大星星** ($10-$50) | 得到以上福利，另外還獲得專屬贊助者專欄、優先入場體驗等獨享服務 |
| **超級星星** (>$100) | 獲得一切上述福利，另外還能夠與內容作者進行一對一交流、專門設計贊助者限定內容等 |
