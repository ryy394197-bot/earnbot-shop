### 開源/內容創作者贊助變現包

歡迎使用這個開源/內容創作者贊助變現包！本套裝包含 GitHub Sponsors 與 Ko-fi 二選一的推薦方案，以及一系列的工具和資源，幫助您更有效地吸引和支持您的支持者。

#### **GitHub Sponsors vs. Ko-fi 哪個先開？**

在決定是使用 GitHub Sponsors 為主還是 Ko-fi 為主之前，請考慮以下因素：

1. **目標用戶群體**：如果您主要是程式碼開發者和相關社群成員，GitHub Sponsors 可能更適合。如果您的內容與創意或娛樂相關，Ko-fi 或其他類似平台可能更有吸引力。
2. **營收模式偏好**：GitHub Sponsors 提供了預設的贊助價位和回饋機制，如果您希望快速開始並保持簡單，這可能是更好的選擇。如果您想設計更複雜且多樣化的方案，Ko-fi 可能更具吸引力。
3. **社群生態**：檢查您的目標社群是否已有許多 Sponsors 或 Ko-fi 成員，以了解他們對平台的接受程度。

#### **個人頁一句定位**

打造一個引人注目的個人頁面是吸引贊助者的第一步。請確保在這裡清楚地傳達您的故事、使命和價值觀：

- **介紹**：簡短明瞭地描述您自己和您的創作或開發領域。
- **目標與影響力**：分享您希望通過此平台實現的目標，以及對社群可能產生的積極影響。
- **特色項目**：列出您最自豪的作品或專案，並解釋為什麼這些是獨特且值得贊助的原因。

#### **三檔贊助價位與回饋**

為了確保您的方案既富有吸引力又具體可達，我們提供了以下三種贊助價位：

1. **基本版**：每月 $5 赞助者會獲得：
   - 一則專屬的 GitHub Sponsors/ Ko-fi 連結
   - 在個人頁面上展示支持者的標誌或圖像（需事先同意）
2. **進階版**：每月 $10 赦助者會獲得：
   - 上述基本版的所有回饋，加上：
     - 一張專屬的贊助感謝照片
     - 在 GitHub/ Ko-fi 網站上的特別標誌或徽章
3. **尊享版**：每月 $20 赦助者會獲得：
   - 上述進階版的所有回饋，加上：
     - 一場專屬的線上交流機會（例如 Q&A）
     - 在個人頁面上展示贊助者的標誌或圖像
     - 特別訪談機會

#### **README／文章 CTA 範本**

為您的內容創作者網站、博客或其他平台開發一個強大的 Call-to-Action (CTA) 連結，鼓勵讀者轉向支援您：

**GitHub Sponsors 貼文範例：**
```
要支持我的工作嗎？請考慮成為我的 GitHub Sponsors 成員：
https://github.com/sponsors/yourusername
贊助 $5 每月，獲得獨家回饋！
```

**Ko-fi 貼文範例：**
```
想為我的創作或開發努力打氣嗎？請考慮支持我：
https://ko-fi.com/yourusername
贊助 $5 每月，獲得 exclusive 回饋！
```

#### **禁止事項**

1. **假數據**：不要使用虛構的贊助者數字或名單。
2. **買粉**：請確保所有贊助回饋都是真實的，並與您的社群成員互動。
