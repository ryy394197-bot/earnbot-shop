### 二、建立專案結構與基本功能

接下來，建立專案的目錄結構。一個基本的 CLI 工具專案通常包含以下幾個部分：

- `main.py`：主程式，處理命令行參數與執行邏輯。
- `README.md`：專案說明文件。
- `setup.py`：用於安裝與打包。
- `requirements.txt`：依賴管理。

在 `main.py` 中，你可以使用 `argparse` 模組來處理命令行參數。例如：

```python
import argparse

def generate_readme():
    print("Generating README...")

if __name__ == "__main__":
    parser = argparse.ArgumentParser(description="Generate a README file.")
    parser.add_argument("--template", help="Choose a template for README.")
    args = parser.parse_args()

    generate_readme()
```

這只是最基本的功能，你可以根據需求擴展更多參數與功能。
