## 引言

在這個時代，我們往往會用一些 CLI 工具來完成特定的工作任務；有些工具可能只是簡單的命令行指令，但另一些則可以做更多有趣的事情（比如生成 Markdown 文檔、管理 Git 檔案等等）。這篇文章將教你如何把這些工具做成作品集，並藉此引流到付費指南／進階技巧包。

### 例子：`git-crypt`

我們以 `git-crypt` 工具為例。這個 CLI 工具可以幫助你加密和解密 Git 檔案夾中的檔案。它支援多種加密方式，包括 AES-256 和 Blowfish 等等。

### 安裝

首先，你需要在你的系統上安裝 `git-crypt`。你可以從 GitHub 的官方存儲庫下載最新版本的程式碼：https://github.com/AGWA/git-crypt


```bash
# Clone the repository
git clone https://github.com/AGWA/git-crypt.git

# Navigate to the project directory
cd git-crypt

# Install dependencies using pip
pip install -r requirements.txt

# Build and install the binary
python setup.py build && python setup.py install
```

### 使用 `git-crypt` 加密 Git 檔案夾中的檔案

在建立作品集之前，我們先來看看如何使用 `git-crypt` 進行加密。假設你有一個名為 `my_project` 的 Git 檔案夾。

```bash
# 首先，初始化 git-crypt
git-crypt init my_project/

# 加密檔案
git-crypt encrypt -d --add my_project/
```

### 使用 `git-crypt` 解密 Git 檔案夾中的檔案

接下來，我們將展示如何使用 `git-crypt` 进行解密。假設你有一個名為 `my_project` 的 Git 文件夹。

```bash
# 首先，初始化 git-crypt
git-crypt init my_project/

# 加密檔案
git-crypt encrypt -d --add my_project/
```

### 建立作品集

現在，我們已經知道如何使用 `git-crypt` 來加密和解密 Git 文件夹。接下來，你可以將這些命令整合到一個簡單的 CLI 工具中，並建立一個 GitHub 網站作為你的作品集。

```bash
# 首先，在 GitHub 上創建一個新的專案
gh repo create my-portfolio

# 在專案文件夾中建立一個 index.js 文件
echo "const { encrypt, decrypt } = require('git-crypt');"

echo "module.exports = async (options) => {"
echo "  return new Promise((resolve, reject) => {"
echo "    const command = options.command;"
echo "    if (command === 'encrypt') {"
echo "      encrypt(options.path);"
echo "      resolve('File(s) have been encrypted.');"
echo "    } else if (command === 'decrypt') {"
echo "      decrypt(options.path);"
echo "      resolve('File(s) have been decrypted.');"
echo "    } else {"
echo "      reject(new Error(`Unknown command: ${command}`));"
echo "    }"
echo "  });"
echo "};"

# 在 GitHub 上建立一個 README.md 文件
cat << EOF > README.md
# My Portfolio

A collection of CLI tools and scripts I've developed.

## git-crypt

A simple CLI tool for encrypting and decrypting Git files.
EOF

# 在專案文件夾中建立一個 package.json 文件
echo '{ "name": "my-portfolio", "main": "./index.js" }' > package.json
```

最後，你可以將這些 CLI 工具整合到一個更完整的付費指南或進階技巧包中。例如，你可以提供一些額外的加密策略、更複雜的命令行指令以及如何使用 `git-crypt` 進行多個 Git 檔案夾之間的檔案同步。
