用一個下午做完並開源一個 Python CLI：實踐指南

在軟體開發領域，CLI（Command Line Interface）是一種常見的介面設計，使使用者可以透過命令行控制程式的執行。然而，建立一個完整且功能強大的 CLI 卻是一個耗時耗力的任務。這篇文章將帶您一步步地實踐如何用一個下午做完並開源一個 Python CLI。

**準備環境**

首先，您需要確保您的環境符合建立 CLI 的需求。建議使用 Python 3.8 或更高版本，搭配 pip 套件管理器。

```bash
# 安裝必要的套件
pip install --user click requests
```

**實作步驟 1：選擇框架**

選擇適合您的 CLI 框架。這裡，我們將使用 Click 框架，因為它易於使用且功能強大。

```python
import click

@click.group()
def cli():
    pass

@cli.command()
def hello():
    """prints a greeting message"""
    click.echo('Hello, World!')

if __name__ == '__main__':
    cli()
```

**實作步驟 2：添加功能**

繼續增加 CLI 的功能。讓我們新增一個可以抓取 GitHub API 資料的命令。

```python
import click
import requests

@cli.command()
def get_github_repo():
    """prints a list of GitHub repositories"""
    repo_list = requests.get('https://api.github.com/users/octocat/repos').json()
    for repo in repo_list:
        click.echo(repo['name'])
```

**實作步驟 3：設定配置**

增加一個選項讓使用者能夠自定義 CLI 的配置。這裡，我們將使用 Click 自帶的選項功能。

```python
@cli.command()
@click.option('--username', prompt='Your GitHub username',
              help='The GitHub username to use.')
def get_github_user(username):
    """prints a list of GitHub repositories for the given username"""
    repo_list = requests.get(f'https://api.github.com/users/{username}/repos').json()
    for repo in repo_list:
        click.echo(repo['name'])
```

**常見錯誤**

錯誤 1：未正確安裝 Click 框架。請務必使用 pip 安裝相關套件。

錯誤 2：配置選項未被正確設定。請檢查您的配置檔案，並確認是否正確設置了環境變數。
