# 用一個下午做完並開源一個 Python CLI

Python CLI 是開發者的常用工具，但要從零開始建立一個，可能讓初學者感到困難。本文將分享如何利用有限的時間和資源，在短短的一個下午內創建出一個簡單的 Python Command Line Interface (CLI) 程式，並提供一些常見錯誤的解決方法。

## 1. 創建 CLI 的基本框架

首先，確保你的開發環境已經設置好。可以使用 `virtualenv` 或者 `conda` 來建立虛擬環境。接著安裝必要的套件：

```bash
pip install click
```

接下來，我們將創建一個簡單的 CLI 程式，該程式會接受使用者輸入並回應一個簡單的訊息。以下是基本框架：

### main.py

```python
import click

@click.command()
def hello():
    """A simple command line application."""
    name = click.prompt('Your name', type=str)
    print(f'Hello, {name}!')

if __name__ == '__main__':
    hello()
```

## 2. 建立 CLI 的功能與輸入驗證

接下來，我們可以加入更多的功能和輸入驗證。例如，讓使用者能夠指定命令的參數：

### main.py

```python
import click

@click.command()
@click.option('--name', prompt=True, help='Your name')
def hello(name):
    """A simple command line application."""
    print(f'Hello, {name}!')

if __name__ == '__main__':
    hello()
```

## 3. 增加進階功能

為了增加 CLI 的功能性，可以考慮加入更複雜的命令行參數和回應。例如，讓使用者能夠指定命令並接收多個輸入：

### main.py

```python
import click

@click.command()
@click.option('--name', prompt=True, help='Your name')
@click.argument('args', nargs=-1)
def hello(name, args):
    """A simple command line application."""
    print(f'Hello, {name}! You entered: {" ".join(args)}')

if __name__ == '__main__':
    hello()
```
