Python CLI 可以做什麼？以及如何用一個下午做出一個？
Python 是一種強大的程式語言，被廣泛使用於解決各種問題。其中，Command Line Interface (CLI) 是 Python 程式設計中的一種常用模式。透過 CLI，使用者可以直接在命令行輸入指令來執行特定的功能，而不需要編寫繁複的介面。因此，Python CLI 可以做許多事情：從簡單的資料分析到複雜的自動化腳本；從文字處理到網路爬蟲等等。

但你可能好奇，一個 Python CLI 真能用一個下午做出來嗎？答案是肯定的！本文將介紹如何使用 Python CLI 的基本概念、實作技巧和常見問題，幫助你快速上手。最後，我們會一起完成一個簡單且實用的例子：一個可以自動更新程式碼版本控制系統 (VCS) 並推送至 GitHub 的 CLI。
### 創建一個簡單的 CLI

#### 定義功能
首先，我們需要明確要為 CLI 設計什麼功能。以本例來說，我們將設計一個能執行以下任務：
1. 檢查 Git 目錄是否有未提交的更改
2. 如果有，自動更新 Git 版本控制系統並推送到 GitHub

#### 實作步驟
要完成這個 CLI，你需要先安裝 Python 以及 Git。接下來，你可以開始編寫程式碼了。

首先，我們需要導入必要的模組：
```python
import os
import subprocess
```

然後，定義一個函數來執行命令行指令：
```python
def run_command(command):
    result = subprocess.run(command, shell=True, capture_output=True)
    return result.stdout.decode()
```

現在，你可以使用這個函數來檢查 Git 目錄是否有未提交的更改。請注意，你需要將 `./` 替換為你的 Git 檔案夾位置。
```python
git_status = run_command('cd ./ && git status')
if 'nothing to commit, working tree clean' not in git_status:
    print("有未提交的更改")
else:
    print("所有檔案已提交")
```

如果命令行輸出中沒有 "nothing to commit"，則表示 Git 目錄中有未提交的更改。接下來，我們需要執行 `git add .` 和 `git commit -m "your message"` 來將這些更改加入版本控制系統。
```python
if 'nothing to commit' not in git_status:
    print("正在更新 Git 版本控制系統...")
    run_command('cd ./ && git add .')
    run_command('cd ./ && git commit -m "自動更新程式碼"')
```

最後，我們需要將更改推送到 GitHub。
```python
print("正在推送到 GitHub...")
run_command('cd ./ && git push origin main')
```

#### 測試與修改
完成上述步驟後，你可以測試這個 CLI 是否可以正確執行。請確保你已經在 Git 目錄中安裝了 Python 以及必要的模組。

如果你想要更進一步的自訂功能，例如讓使用者輸入 GitHub 帳號和密碼，或是使用 SSH 開啟自動化流程，都可以透過修改上述程式碼來實現。
### 當前常見錯誤
在開發 Python CLI 時，可能會遇到一些問題。以下是一些常見問題及解決方法：

1. **安裝問題**：確保你已經安裝了必要的模組，例如 `subprocess` 和 `os`。如果你的系統上沒有這些模組，可以使用 pip 安裝。
2. **命令執行錯誤**：請檢查你的命令是否正確輸入。如果遇到任何問題，可以嘗試手動在命令行中輸入相同的指令來確認。
3. **版本控制問題**：確保 Git 目錄中有未提交的更改。如果你的程式碼已經提交到 GitHub，則不需要執行 `git add .` 和 `git commit -m "your message"`。
