# 用一個下午做完並開源一個 Python CLI（附實用技巧包）

開發一個 Python CLI（命令行工具）聽起來可能有些複雜，但事實上，只要掌握正確的步驟，你可以在一個下午內完成一個功能完整的開源專案，並透過它引流、甚至創造額外收益。本文將帶你一步步走過整個過程，並分享一些實用技巧，幫助你輕鬆上手。

---

## 一、準備工具與環境

首先，你需要確保你的開發環境已安裝 Python（建議使用 Python 3.8 以上版本）和 pip。如果你還沒有安裝，可以透過 [Python 官方網站](https://www.python.org/) 下載並安裝。

接下來，我們需要一個專案結構。你可以使用 `cookiecutter` 或 `poetry` 來快速建立專案。如果你是新手，建議使用 `poetry`，它會自動管理依賴與虛擬環境。

```bash
pip install poetry
poetry new my_cli
cd my_cli
```

這會建立一個專案結構，包含 `pyproject.toml` 和 `src/` 資料夾。你可以在此基礎上進行開發。

---

## 二、開發 CLI 功能

CLI 的核心是處理命令行參數。Python 中最常用的是 `argparse` 模組，它能幫助你輕鬆解析用戶輸入的參數。

在 `src/my_cli/main.py` 中，我們可以寫一個簡單的 CLI 工具，用來計算兩個數字的總和：

```python
import argparse

def add_numbers(a, b):
    return a + b

def main():
    parser = argparse.ArgumentParser(description="Add two numbers.")
    parser.add_argument("a", type=int, help="First number.")
    parser.add_argument("b", type=int, help="Second number.")
    args = parser.parse_args()
    result = add_numbers(args.a, args.b)
    print(f"The sum of {args.a} and {args.b} is {result}.")

if __name__ == "__main__":
    main()
```

這段程式碼會解析兩個整數參數 `a` 和 `b`，並輸出它們的總和。

## 三、打包與發布到 GitHub

完成開發後，你需要將專案打包並發布到 GitHub，以便其他人使用與貢獻。

1. **初始化 Git 並提交程式碼**：

```bash
git init
git add .
git commit -m "Initial commit"
```

2. **建立 GitHub 專案**：

前往 [GitHub](https://github.com/) 建立一個新專案，並將本地專案推送到遠端。

```bash
git remote add origin https://github.com/your-username/my_cli.git
git push -u origin main
```

3. **發布到 PyPI（可選）**：

如果你希望用戶能透過 `pip install` 安裝你的 CLI，可以將專案發布到 PyPI。你可以在 `pyproject.toml` 中設置相關資訊，並使用 `poetry publish` 發布。

## 四、常見錯誤與解決方法

- **忘記處理錯誤輸入**：確保你的 CLI 能處理非預期的輸入，例如非整數的參數。你可以使用 `try-except` 來捕捉錯誤。
- **未提供使用說明**：在 CLI 中加入 `--help` 選項，讓用戶知道如何正確使用你的工具。
- **未寫 README**：一個清晰的 README 是專案成功的第一步。它應包含功能簡介、安裝方式、使用範例和貢獻方式。

## 五、如何透過開源工具引流與變現

將 CLI 開源後，你可以透過以下方式引流並創造收益：

1. **GitHub 專案頁面引流**：在 README 中加入清晰的使用教學與功能說明，並加入「使用指南／進階技巧包」的購買連結。
