# 用一個下午做完並開源一個 Python CLI：從零到 GitHub 的完整指南

在現代開發者的世界裡，CLI（命令行工具）因其輕量、高效與可組合性，成為開發者日常工作中不可或缺的工具。如果你正在尋找一個快速、實用的項目來提升自己的技術履歷，或者想透過開源工具引流，並進一步轉化為付費教學資源，那麼用一個下午打造一個 Python CLI 是一個絕佳的選擇。

---

## 1. 準備工具與環境

在開始之前，你需要確保自己的開發環境已經準備好。以下是你需要的：

- **Python 3.8 或更高版本**：CLI 工具通常基於 Python 實現，輕便且跨平台。
- **GitHub 帳號**：用於開源你的 CLI 工具。
- **VS Code 或 PyCharm**：用於編寫與調試代碼。
- **基本的命令行知識**：如 `pip install`, `git commit`, `git push` 等。

如果你是剛入門開發者，可以從簡單的 CLI 功能開始，例如：生成隨機密碼、格式化 JSON、或處理文字內容。

---

## 2. 快速建立 CLI 工具

### 第一步：建立專案結構

在本地創建一個專案資料夾，並初始化一個 Python 專案：

```bash
mkdir my_cli
cd my_cli
python3 -m venv venv
source venv/bin/activate
pip install click
```

使用 `click` 套件可以輕鬆建立 CLI 工具，它讓你能夠簡單地定義命令與參數。

### 第二步：編寫功能代碼

創建一個 `main.py` 檔案，並加入以下代碼：

```python
import click

@click.command()
@click.argument('text')
def uppercase(text):
    click.echo(text.upper())

if __name__ == '__main__':
    uppercase()
```

這是一個簡單的 CLI，用來將輸入的文字轉換為大寫。你可以根據自己的需求調整功能。

### 第三步：打包與安裝

使用 `setup.py` 來打包你的 CLI 工具：

```python
from setuptools import setup, find_packages

setup(
    name='my_cli',
    version='0.1',
    packages=find_packages(),
    entry_points={
        'console_scripts': [
            'my-cli=my_cli.main:uppercase',
        ],
    },
)
```

執行以下命令來安裝你的 CLI：

```bash
pip install .
```

現在，你可以在命令行中使用 `my-cli "hello world"` 來測試你的工具。

---

## 3. 開源你的 CLI 工具

將你的 CLI 工具上傳到 GitHub，並設定 `.gitignore` 檔案，避免將虛擬環境等資料提交到遠端倉庫。

在 GitHub 上建立一個專案，並將本地代碼推送到遠端：

```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/your-username/my-cli.git
git push -u origin master
```

你也可以設定 README 檔案，說明你的 CLI 工具功能與使用方法，這有助於吸引更多用戶使用與 Star 你的專案。

---

## 4. 常見錯誤與解決方案

- **忘記設定虛擬環境**：這會導致依賴衝突，建議每次專案都使用 `venv`。
- **未正確設定 `entry_points`**：這會導致 CLI 命令無法執行。
- **未寫 README 或說明文件**：這會影響用戶對你的工具的使用體驗與專案的可見度。
- **未做單元測試**：CLI 工具應具備穩定性，測試能幫助你發現潛在問題。

## 5. 如何轉化為付費教學資源

開源工具本身可以為你帶來流量與關注，但如果你想要進一步轉化為收入，可以考慮提供「使用指南／進階技巧包」。

你可以在 GitHub 專案頁面中加入一個 `/shop/` 或 `/market/` 的連結，提供以下內容：

- **完整使用教學**：從安裝、配置、使用到常見問題解答。
- **進階技巧**：如如何擴展 CLI 功能、整合到自動化流程、與其他工具搭配使用等。
- **專屬支援**：為購買者提供個人化幫助，提升用戶體驗。
