### 用一個下午做完並開源一個 Python CLI

#### 引言
Python 是一種強大的編程語言，可用於各種不同的應用程式開發。然而，許多 Python 程式碼都散落在各個檔案中，缺乏一個統一的入口點。此外，許多 Python CLI 工具往往需要先安裝第三方套件才能使用，導致初學者難以上手。本篇文章將介紹如何用一個下午完成並開源一個 Python CLI，讓使用者可以輕鬆地在命令列中執行程式碼，並且不需要額外的安裝套件。

#### 第一階段：建立基本結構
首先，我們創建一個新的 Git 公開專案，取名為 `command-line-tool`。接著，在專案根目錄下建立 `main.py` 這個檔案，這是我們 CLI 工具的核心程式碼。
```python
# main.py

def hello_world():
    print("Hello, World!")
```
接下來，我們需要設定一個命令行接口 (CLI) 指令來呼叫這個函式。在專案根目錄下建立 `command_line_tool` 命名空間，並將其設為主程式。
```python
# command_line_tool/__init__.py

from .main import hello_world  # 寫入這個檔案

def main():
    hello_world()
```
最後，我們需要在 CLI 中定義一個命令來呼叫 `hello_world` 函式。在專案根目錄下建立 `command_line_tool/cli.py` 檔案。
```python
# command_line_tool/cli.py

import click  # 寫入這個檔案

@click.command()
def cli():
    main()

if __name__ == "__main__":
    cli()
```
現在，我們已經完成了一個簡單的 CLI 工具。在命令列中輸入 `command-line-tool` 就可以直接執行這段程式碼。

#### 第二階段：添加更多功能
接下來，我們將增加一些功能來讓這個 CLI 更加實用。首先，我們會新增一個命令來顯示當前日期和時間。
```python
# command_line_tool/cli.py

import datetime  # 寫入這個檔案
from .main import hello_world, cli  # 寫入這個檔案

@click.command()
def show_time():
    current_time = datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    print(f"Current time: {current_time}")

cli.add_command(show_time)
```
現在，如果在命令列中輸入 `command-line-tool show-time` 就可以顯示當前日期和時間。

#### 第三階段：增加使用指南
為了讓使用者更容易上手這個 CLI 工具，我們會新增一個使用指南。首先，在專案根目錄下建立一個新的 Markdown 檔案，取名為 `README.md`。
```markdown
# Command Line Tool

This is a simple command line tool for Python.

## Usage
To use this tool, simply run the following command in your terminal:
```
command-line-tool [COMMAND]
```

Available commands are:
- `show-time`: Displays current date and time.
```
現在，如果在命令列中輸入 `command-line-tool --help` 就可以看到這個使用指南。

#### 第四階段：處理錯誤
最後，我們會增加一些基本的錯誤處理。首先，在 `main.py` 中新增一個函式來處理程式碼中的錯誤。
```python
# main.py

def hello_world():
    try:
        print("Hello, World!")
    except Exception as e:
        print(f"Error: {e}")

def handle_error(error):
    if isinstance(error, ValueError):
        print("Value error occurred.")
    elif isinstance(error, TypeError):
        print("Type error occurred.")

try:
    hello_world()
except Exception as e:
    handle_error(e)
```
接下來，我們需要在 CLI 中處理這些錯誤。首先，在 `cli.py` 中新增一個函式來處理程式碼中的錯誤。
```python
# command_line_tool/cli.py

def cli():
    try:
        main()
    except Exception as e:
        handle_error(e)

if __name__ == "__main__":
    cli()
``
