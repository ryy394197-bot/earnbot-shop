#### 一、引言
在開始之前，我們需要準備一個基本的 Python 環境。如果你已經有 Python 安裝好了，可以直接跳到第二步；若沒有，可以先安裝 Python 和 pip（Python 的包管理工具）。

#### 二、實作段落

##### 第一步：建立 CLI 輸入
首先，我們需要讓使用者輸入名稱和年齡。這部分非常簡單，只需要使用 `input()` 函式即可：

```python
import sys

print("請輸入您的姓名:")
name = input()
print("請輸入您的年齡:")
age = int(input())
```

##### 第二步：顯示輸出結果
接下來，我們需要將使用者提供的名稱和年齡回傳給使用者。這部分也可以使用 `input()` 函式：

```python
print(f"您好,{name}! 您今年{age}歲了。")
```

##### 第三步：整合成 CLI 工具
現在，讓我們把上面的程式碼組合成一個完整的 CLI 工具。首先，我們需要定義一個函式來處理使用者的輸入和回應：

```python
def main():
    print("歡迎使用姓名與年齡查詢工具!")
    name = input("請輸入您的姓名:")
    age = int(input("請輸入您的年齡:"))
    print(f"您好,{name}! 您今年{age}歲了。")

if __name__ == "__main__":
    main()
```

##### 第四步：執行 CLI 工具
現在，你可以直接運行這個 Python 程式碼來測試你的 CLI 工具：

```bash
python cli_tool.py
```
