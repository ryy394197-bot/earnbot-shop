# 平台抽成 1.5% 怎麼跟供給需求方說清楚

## 引言

現在有許多平台採用「平台抽成」的模式，例如「GitHub」、「HashNode」等。這些平台會從供給者（作者、開發者）或需求者（使用者）取得收益中收取一定的比例作為費用，這被稱為「平台抽成」。

以 HashNode 來說，他們採用的是「1.5% 抽成」的模式；而 GitHub 则是提供「免費版」及「專業版」兩種不同的服務。其中，供給者（作者）若選擇使用「專業版」則需支付額外費用，平台會從其收入中收取 1.5% 的費用。

## 如何與供給需求方說清楚？

### 確定是否需要抽成

在決定採用平台抽成模式之前，首先必須明確了解自己是否真的需要「抽成」。如果供給者和需求者之間已經有良好的溝通管道，並且能夠進行直接交易，那麼就不必使用平台抽成模式。

### 清晰描述抽成比例

在與供給需求方溝通時，一定要清楚地說明平台抽成的比例。例如，HashNode 提供的是 1.5% 抽成的服務，因此作者需要支付的費用也為 1.5%；而 GitHub 则是從專業版用戶的收入中收取 1.5% 的費用。

### 優化溝通方式

在與供給需求方溝通時，可以考慮使用「架站媒合」的方式。例如，GitHub 提供的是「免費版」及「專業版」兩種不同的服務；而 HashNode 则是提供「免費版」及「Premium」兩種不同的服務。

### 降低強制性

在提供平台抽成模式時，可以考慮降低其強制性。例如，HashNode 提供的是「1.5% 抽成」的服務；但 GitHub 却提供「免費版」及「專業版」兩種不同的服務，其中並未有強制性的規定。

### 兩方溝通

在與供給需求方溝通時，一定要確保他們了解平台抽成模式。例如，在使用 HashNode 的過程中，作者可以清楚地看到自己所收到的收益；而在 GitHub 中，則需要自行計算專業版用戶的收入。
