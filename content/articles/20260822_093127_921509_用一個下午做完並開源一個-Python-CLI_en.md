# 用一個下午做完並開源一個 Python CLI

在忙碌的程式開發工作中，我們常常需要執行各種繁瑣且重複的命令。從安裝套件、打包部署到維護版本控制，這些任務往往讓人煩躁不已。然而，若能將這些流程自動化為 CLI（Command Line Interface）工具，不僅可以大幅提高效率，還能讓團隊共享資源，共同提升開發體驗。

本文即將帶大家一起完成一個簡單的 Python CLI 工具——**`auto-deployer`**。我們會從需求分析、設計實現到測試發布的過程進行細節分享，希望能夠幫助你更快地上手並啟發出更多創意。

## 1. 需求分析

首先，我們要明確這個 CLI 工具想要解決什麼問題？假設你的團隊正在使用 GitLab CI/CD，並且需要在不同環境（如開發、測試、生產）之間進行部署。那麼，一個能夠自動化管理這幾個環境的工具將大有用場。

### 1.1 具體需求
- 支持多種環境配置（例如：`dev`, `test`, `prod`)
- 自動化部署流程（如拉取最新代码、安装依赖、运行测试等）
- 管理不同环境下的数据库连接信息

### 2.3 部署邏輯
最後，我們需要實現部署的具體邏輯。這包括拉取代码、安装依赖、运行测试等步骤。

```python
import os
import subprocess

def deploy_to_environment(auto_deployer, environment):
    config = auto_deployer.config[environment]
    
    # 拉取代码并安装依赖
    git_url = config["git_url"]
    print(f"Cloning {git_url}...")
    os.system(f"git clone {git_url}")
    project_dir = f"{git_url.split('/')[-1]}"
    os.chdir(project_dir)
    subprocess.run(["pip", "install", "-r", "requirements.txt"])
    
    # 配置数据库连接
    database_config = config["database"]
    db_connection_string = f"postgresql://{database_config['user']}:{database_config['password']}@{database_config['host']}:{database_config['port']}/your_db_name"
    subprocess.run(["psql", "-c", f"SET PGPASSWORD='{database_config['password']}'"], env={"PGPASSWORD": database_config["password"]})
    
    # 运行测试
    test_command = "pytest tests/"
    print(f"Running tests...")
    subprocess.run(test_command, shell=True)
```
