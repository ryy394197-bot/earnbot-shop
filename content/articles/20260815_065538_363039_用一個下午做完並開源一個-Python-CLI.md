# 用一個下午做完並開源一個 Python CLI

## 3-5 個實作段落

### 應用場景
假設你是一名資料科學家，每天都要處理大量的 CSV 檔案。然而，這些檔案往往需要特定的格式才能進行分析。為了節省時間和提高效率，你可以撰寫一個 CLI 工具來自動化這個過程。

### 執行環境
這是一個完整的 Python 3 實作範例：

```python
import csv
from datetime import datetime

def process_csv(file_path, output_dir):
    # 讀取 CSV 檔案內容
    with open(file_path, 'r') as file:
        reader = csv.DictReader(file)
        data = list(reader)

    # 篩選特定欄位
    filtered_data = [row for row in data if datetime.strptime(row['Date'], '%Y-%m-%d').date() >= datetime.now().date()]

    # 寫入處理後的 CSV 檔案
    output_file_path = f'{output_dir}/filtered_{datetime.now().strftime("%Y%m%d")}.csv'
    with open(output_file_path, 'w', newline='') as file:
        fieldnames = ['Date', 'Value']  # 篩選欄位名稱
        writer = csv.DictWriter(file, fieldnames=fieldnames)
        writer.writeheader()
        for row in filtered_data:
            writer.writerow(row)

if __name__ == '__main__':
    import argparse

    parser = argparse.ArgumentParser(description='Process CSV files and filter based on date')
    parser.add_argument('file_path', type=str, help='Path to the input CSV file')
    parser.add_argument('--output_dir', type=str, default='./filtered/', help='Output directory for processed files')

    args = parser.parse_args()

    process_csv(args.file_path, args.output_dir)
```

### 常見錯誤
在開發過程中可能遇到的一些問題包括：
- CSV 檔案不存在或路徑不正確。
- 篩選條件有誤，導致無資料可處理。

### 使用方法
要使用這個 CLI，只需執行以下命令：

```bash
python -m script.process_csv input.csv output/
```
