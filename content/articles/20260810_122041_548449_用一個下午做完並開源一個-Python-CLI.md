### 第一步：定義你的要求

首先，你必須明確要實現什麼功能。為了讓示範更具體，我們將建立一個簡單的「猜數字遊戲」。這個 CLI 會讓使用者輸入一個下限和上限，然後通過隨機產生一系列號碼進行玩。

```python
import random

def guess_number():
    lower = int(input("請輸入下限："))
    upper = int(input("請輸入上限："))

    if lower > upper:
        print("錯誤！下限不能大於上限。")
        return

    secret_num = random.randint(lower, upper)
    attempts = 0
    while True:
        guess = input(f"猜一數字在 {lower} 到 {upper} 之間（含 {lower} 和 {upper})： ")
        if int(guess) == secret_num:
            print("恭喜！你猜對了!")
            break
        elif int(guess) < secret_num:
            print("太低了，試試高點的數字。")
        else:
            print("太高了，試試低點的數字。")

if __name__ == "__main__":
    guess_number()
```

### 第二步：設計 CLI 的使用者體驗

接下來，你需要將這個程式轉變為一個CLI。這可以通過在 `input` 函數前面加上 `sys.stdin.readline()` 進行實現。

### 第三步：將程式整理成 CLI

最後，你需要將這個程式以 CLI 的形式呈現給使用者。你可以通過在 `__main__` 函數中執行程式來實現。
