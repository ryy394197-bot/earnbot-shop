### 用一個下午做完並開源一個 Python CLI

在科技領域，創建一個簡單的工具就能輕鬆實現個人價值。Python 是一種功能強大的程式語言，適合開發各種命令行界面（CLI）。本篇文章將介紹如何在一整天內完成一個基本的 Python CLI 工具，並分享一些使用技巧和常見錯誤。

#### 引言
在現代技術領域，開源工具是利基市場上的寶貴財富。它們可以輕鬆實現個人價值，並且能夠吸引志同道合的人群。如果你對 Python 程式語言有一定了解，那麼本文將教你如何在一整天內完成一個簡單的 CLI 工具。

#### 1. 創建基本結構
首先，你需要創建一個新的 Git 仓库來存儲你的工具程式碼。你可以使用 GitHub 或者其他開源托管平台。

```bash
mkdir my_cli_tool && cd $_
git init
```

接著，編寫基本的 CLI 程式碼。以下是一個簡單的例子，用於計算兩個數字之和：

```python
# main.py

def add(a, b):
    return a + b

if __name__ == "__main__":
    import argparse
    parser = argparse.ArgumentParser(description="Add two numbers")
    parser.add_argument('num1', type=int)
    parser.add_argument('num2', type=int)
    args = parser.parse_args()
    print(add(args.num1, args.num2))
```

#### 2. 安裝和測試 CLI 工具
使用 `pip` 設定 Python 環境，並運行 CLI 應用程式。你可以在 Git 仓库中建立一個 `requirements.txt` 文件來列出必要的庫：

```bash
pip install -r requirements.txt
```

然後在主檔案目錄下執行：

```bash
python3 main.py
```

#### 3. 優化和擴展功能
根據需求，你可以進一步優化 CLI 工具。例如，添加更詳細的使用說明、錯誤處理以及更多功能。

- **使用說明**：可以通過命令行參數 `-h` 或 `--help` 提供幫助信息。
  
  ```python
  parser.add_argument('-h', '--help', action='store_true')
  if args.help:
      print(parser.format_help())
      exit()
  ```

- **錯誤處理**：當輸入格式不正確時，提供清晰的錯誤訊息。

  ```python
  try:
      result = add(args.num1, args.num2)
  except ValueError as e:
      print(f"Error: {e}")
      parser.print_help()
      exit(1)
  ```

#### 4. 常見錯誤和解決方法

- **Imports 誤用**：確保正確地導入必要的庫，避免 `ModuleNotFoundError`。
  
  ```bash
  pip install argparse
  ```
  
- **缺少參數解析**：檢查是否正確使用了 `argparse.ArgumentParser`。

  ```python
  parser = argparse.ArgumentParser(description="Add two numbers")
  parser.add_argument('num1', type=int)
  parser.add_argument('num2', type=int)
  ```

#### 5. 完成和開源工具
一旦你完成了 CLI 工具，可以考慮將它公開到 GitHub 上。這樣做不僅能夠讓更多人知道你的工作，還能吸引志同道合的人合作。

```bash
git add .
git commit -m "Add basic addition functionality"
git push origin main
```
