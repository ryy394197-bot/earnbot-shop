### 二、快速開發：用 Python 與 Click 建立 CLI

Python 是開發 CLI 工具的首選語言，而 `Click` 則是簡化 CLI 開發的強大工具。安裝 `Click` 後，你可以輕鬆地建立一個結構清晰的 CLI 工具。

以下是一個簡單的範例：

```python
import click

@click.command()
@click.argument('name')
def greet(name):
    click.echo(f'Hello, {name}!')

if __name__ == '__main__':
    greet()
```

這段程式碼會讓你執行 `python greet.py John` 時，輸出 `Hello, John!`。你可以根據自己的需求擴展更多命令與參數。

優化方面，可以考慮加入 `--version` 或 `--help` 等標準參數，讓 CLI 更符合常見的使用習慣。
