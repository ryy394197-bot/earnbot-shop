**Title:** 如何寫出能吸引使用者的開源工具 README? 避免這些常見錯誤

---

### 實用小工具與程式碼分享是現代開發者的必備技能。然而，要讓你的開源工具被更多人發現並使用卻不是一件容易的事。一篇功能齊全、簡潔易懂的 README 就能讓使用者更容易地找到你想要傳達的信息，而避免常見錯誤則能確保你的工具更受歡迎。

#### 1. **明確說明如何安裝與設定**
- **錯誤**: "先克隆 repo 然後運行 `npm install`"。
- **改進**: 提供完整的安裝指南，包括系統需求、環境設置步驟等。比如：
```
# 安裝 Node.js (如果尚未安裝)
curl -sL https://rpm.nodesource.com/setup_14.x | bash -
yum install -y nodejs

# 克隆 repo
git clone [repo-url] && cd [repo-name]

# 安裝 dep
npm install
```
- **建議**: 使用 `![]()` 高亮顯示命令，使用語法高亮工具（如 Prism.js）來美化程式碼。

#### 2. **提供完整的使用範例**
- **錯誤**: "請看 README 檔案中的示例"。
- **改進**: 在 README 中加入多種不同情境下的使用案例。比如：
```
# 使用範例
## 基本用法
const [tool] = require('[tool-name]')
[tool].doSomething()

## 連接 API
const client = new Client({
  url: 'https://api.example.com'
})
client.fetchData()
```
- **建議**: 提供線上 Demo 或使用 CodePen、JSFiddle 等工具來展示範例。

#### 3. **提供完整的錯誤解決方案**
- **錯誤**: "請查看 GitHub Issue 與已知問題"。
- **改進**: 在 README 中列出常見問題及解決方法。比如：
```
# 常見問題與解答
## 問: 我收到 `Error: Cannot find module '[module-name]'` ？
答: 確保你已經安裝了所需模組，並重新啟動 Node.js。
```
- **建議**: 使用 Markdown 列表來組織內容。

#### 4. **提供進階使用技巧**
- **錯誤**: "請查看 Issue 與已知問題"。
- **改進**: 在 README 中加入進階使用技巧。比如：
```
# 迴購與貯藏
const [tool] = require('[tool-name]')
[tool].saveData(data)
const savedData = await [tool].loadSavedData()
```
- **建議**: 使用語法高亮工具來美化程式碼。

#### 5. **提供常見問題解答**
- **錯誤**: "請查看 GitHub Issue 與已知問題"。
- **改進**: 在 README 中列出常見問題及解決方法。比如：
```
# 常見問題與解答
## 問: 我收到 `Error: Cannot find module '[module-name]'` ？
答: 確保你已經安裝了所需模組，並重新啟動 Node.js。
```
- **建議**: 使用 Markdown 列表來組織內容。

### 避免這些常見錯誤

#### 提供完整且易於找到的資訊
- **錯誤**: "請查看 Issue 與已知問題"。
- **改進**: 在 README 中提供完整的解決方案，避免使用者需要在其他地方尋找答案。
- **建議**: 使用語法高亮工具來美化程式碼。

#### 提供清晰、易於理解的指示
- **錯誤**: "請看 README 檔案中的示例"。
- **改進**: 在 README 中加入多種不同情境下的使用案例，並提供線上 Demo 或 CodePen 等工具來展示範例。
- **建議**: 使用 Markdown 列表來組織內容。

#### 提供完整且易於理解的錯誤解決方案
- **錯誤**: "請查看 Issue 與已知問題"。
- **改進**: 在 README 中列出常見問題及解決方法，並使用語法高亮工具來美化程式碼。
- **建議**: 使用 Markdown 列表來組織內容。

### CTA

如果你希望你的開源工具能吸引更多使用者，不妨考慮以下方案：

- 提供免費的使用指南或進階技巧包
- 建立一個專屬網站（如 /shop/）提供相關商品
- 將開源工具放入 ComputeGate /market/ 進行銷售
