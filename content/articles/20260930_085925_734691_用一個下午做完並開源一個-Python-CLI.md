#### 2. 建立 CLI 應用程式
接下來，我們將使用 Click 库來建立一個簡單的 Python CLI。Click 是一個強大的命令行接口庫，它讓建立 CLI 具有更高的效率和靈活性。

```python
# cli.py

import click

@click.command()
@click.option('--text', help='輸入一段文字')
def hello(text):
    """Hello World in Click"""
    if text:
        print(f'你好！{text}')
    else:
        print('你好，世界！')

if __name__ == '__main__':
    hello()
```
