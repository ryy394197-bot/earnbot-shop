標題：一個下午做出 Python CLI，並免費開源！
在這個瞬息萬變的時代，你是否也在尋找一個能讓你的技能得到肯定和應用的方法？如果你是個 Python 程式設計師，並且對開發命令列介面（CLI）有興趣，那本文將會是你要找的答案。我花了不到 1 小時就完成了一個簡單的 CLI，而且還把它免費開源了！
首先，我們先來看看這個 CLI 的功能：你可以輸入一個數字，然後它會顯示出該數字的所有因數。例如，如果你輸入「4」，那麼它的因數就是「1, 2, 4」；如果是「6」，那便是「1, 2, 3, 6」。
這個 CLI 無需任何額外的庫或模組，完全使用 Python 基本函式就能完成。以下是我如何製作這個 CLI 的步驟：

### 第一步：選擇程式設計工具
首先，我們需要一個編輯器來撰寫程式碼。我個人推薦 Visual Studio Code（VSCode），因為它有強大的語法高亮、快捷鍵和各種插件功能。如果你尚未安裝 VSCode，請前往其官方網站下載並安裝。

### 第二步：設計 CLI 畫面
接下來，我們來設計這個 CLI 的畫面。在 VSCode 中，你可以使用以下命令來設定一個新的 Python 檔案：
```
touch main.py
```

然後編輯 `main.py` 文件，將其內容修改為以下程式碼：
```python
# main.py

import sys

def find_factors(number):
    factors = []
    for i in range(1, number + 1):
        if number % i == 0:
            factors.append(i)
    return factors

if __name__ == "__main__":
    if len(sys.argv) != 2:
        print("Usage: python main.py <number>")
    else:
        num = int(sys.argv[1])
        result = find_factors(num)
        print(f"{num} 的因數為：{result}")
```

這個程式會從命令列接收一個參數，也就是用戶輸入的數字。我們需要使用 `sys` 模組來取得系統參數。

### 第三步：測試 CLI
在完成編輯後，你可以直接在命令列中執行這個 Python 程式：
```
python main.py 4
```

這應該會顯示「4 的因數為：[1, 2, 4]」。如果你輸入的不是整數，那麼它會提示你使用正確的形式。

### 第四步：開源 CLI
最後一步就是將這個 CLI 公開釋出並開放授權（Open Source）。在 GitHub 上建立一個專案，並將上述程式碼複製到你的主檔案 `main.py`。為了方便其他人使用，你可以添加一些基本的使用說明和範例：
```python
# main.py

import sys

def find_factors(number):
    factors = []
    for i in range(1, number + 1):
        if number % i == 0:
            factors.append(i)
    return factors

if __name__ == "__main__":
    if len(sys.argv) != 2:
        print("Usage: python main.py <number>")
        print("Example:")
        print("python main.py 4")
        print("python main.py 6")
    else:
        num = int(sys.argv[1])
        result = find_factors(num)
        print(f"{num} 的因數為：{result}")
```

在 GitHub 上，你可以建立一個專案、設定 README 檔和添加 LICENSE 文件。如果你希望你的 CLI 可以被更多人使用並作出貢獻，請考慮開放授權方式（例如 MIT 許可或 Apache 2.0 許可）。

### 常見錯誤
在開發這個 CLI 的過程中，可能會遇到一些問題：
- **參數處理錯誤**：確保你的程式可以正確接收和解析命令列參數。
- **範例與說明不足**：提供足夠的示例和使用說明，幫助使用者更好地理解如何使用你的 CLI。
