**用一個下午做完並開源一個 Python CLI**

在軟體開發領域中，CLI (Command-Line Interface) 是一種普遍使用的工具，能夠幫助程式設計師快速完成特定的任務。但是，建立一個完整的 CLI 雖然很有趣，但也是一項耗時和耗力的工作。尤其是在時間緊迫的情況下，怎麼樣才能在短暫的時間內完成CLI的開發呢？

本文將會介紹如何使用 Python 進行CLI的快速建立，並且展示一個實際案例。在這個案例中，我們將會建立一個簡單的 CLI，用於管理 GitHub 的 repository。

### 步驟 1：選擇合適的框架

首先，我們需要選擇一個合適的框架來幫助我們快速建立CLI。Python 中有很多不同的框架可供選擇，例如 Click、 Argparse 等。但是，在這個案例中，我們將會使用最簡單且最常見的框架：Click。

### 步驟 2：定義 CLI 的功能

接下來，我們需要定義 CLI 的功能。為了方便管理 GitHub 的 repository，我們需要實現以下幾個功能：

* 列出所有 repository
* 新增 repository
* 刪除 repository

這些功能可以用 Click 中的 `@click.group()` 函數來實現。

### 步驟 3：實現 CLI 的功能

接下來，我們需要實現每個功能。使用 Click 中的` @click.command()` 函數，我們可以輕鬆地將每個功能進行實現。

```python
import click

@click.group()
def cli():
    pass

@cli.command()
def list_repos():
    # 進行 repository 列出的邏輯
    print("列出所有 repository")

@cli.command()
def add_repo():
    # 進行 repository 新增的邏輯
    print("新增 repository")

@cli.command()
def delete_repo():
    # 進行 repository 刪除的邏輯
    print("刪除 repository")
```

### 步驟 4：測試 CLI

最後，我們需要測試 CLI 是否正常運作。使用 `click.testing.CliRunner()` 函數，我們可以輕鬆地進行測試。

```python
import click.testing

def test_cli():
    runner = click.testing.CliRunner()
    result = runner.invoke(cli, ["--help"])
    assert result.exit_code == 0
    print(result.output)

test_cli()
```
