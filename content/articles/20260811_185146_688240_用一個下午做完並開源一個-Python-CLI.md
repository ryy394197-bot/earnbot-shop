**用一個下午做完並開源一個 Python CLI**

您是否曾經想過可以快速創建一個可執行的命令列介面 (CLI) 來簡化您的工作流程？或許您已經有了一些經驗，但仍然需要花費數小時才能完成。這篇文章將向您展示如何在一個下午內完成並開源一個 Python CLI，讓您可以輕鬆地分享和重用。

### 第一步：選擇一個框架

首先，您需要選擇一個CLI框架來建立您的應用程式。我們將使用 `argparse`，因為它是Python中最常用的CLI框架之一。安裝完成後，您可以創建一個新的Python檔案並導入`argparse`。

```python
import argparse
```

### 第二步：定義命令

下一步是定義您的命令和參數。在這個例子中，我們將建立一個簡單的加法器。您需要創建一個名為 `add` 的子命令，並指定兩個參數 `a` 和 `b`。

```python
parser = argparse.ArgumentParser(description='A simple calculator')
subparsers = parser.add_subparsers(dest='command')

add_parser = subparsers.add_parser('add', help='Add two numbers')
add_parser.add_argument('--a', type=int, required=True)
add_parser.add_argument('--b', type=int, required=True)

args = parser.parse_args()
```

### 第三步：實現邏輯

現在，它是時間來實現您的CLI程式了。在這個例子中，我們需要執行加法運算。您可以使用 `if` 判斷哪個命令被選擇，然後呼叫相應的函數。

```python
if args.command == 'add':
    result = args.a + args.b
    print(f'The result is: {result}')
```

### 第四步：測試和優化

最後一步是測試您的CLI程式是否正確工作。您可以使用 `unittest` 模組來進行單元測試。

```python
import unittest

class TestAddCommand(unittest.TestCase):
    def test_add(self):
        parser = argparse.ArgumentParser()
        subparsers = parser.add_subparsers(dest='command')
        add_parser = subparsers.add_parser('add', help='Add two numbers')
        add_parser.add_argument('--a', type=int, required=True)
        add_parser.add_argument('--b', type=int, required=True)

        args = parser.parse_args(['--help'])
        self.assertEqual(args.command, 'add')

if __name__ == '__main__':
    unittest.main()
```
