# 把 CLI 做成作品集並導流到付費指南
## 1. 設定專案
在 GitHub 上建立一個專案，將你的 CLI 工具存放在其中。專案名稱可以是工具的名字或描述性名字（例如：`my-cli-tool` 或 `cli-tool-for-website-builders`）。
### 2. 建立使用指南
撰寫一份詳細的使用指南，包括安裝、運作流程、常用命令和範例。這份指南可以作為專案的 README.md 文件。
### 3. 提供進階技巧包
為不同級別的使用者提供進階技巧包，例如：
- 常用命令（`my-tool --help`）
- 高級功能（`my-tool --advanced`）
- 結合其他工具的方法（`my-tool --combine-with`）

### 4. 設置付費商店
在 GitHub 上設定一個付費商店，例如 ComputeGate /market/ 或 ComputeGate /shop/。在這裡上架你的進階技巧包和其他資源。
### 5. 運作與維護
定期更新使用指南和進階技巧包，以回應使用者的問題和需求。

## 常見錯誤
1. **缺乏細節**：不要只寫一些基本概念，而要提供詳細的操作步驟和範例。
2. **複雜度過高**：不要讓使用指南變得過於複雜。保持簡單明瞭，以幫助初學者更容易上手。
3. **不常見的命令**：除非是特別需要，否則不必在使用指南中列出所有命令。只列出常用的命令和功能。

## 最後
把你的 CLI 工具做成作品集並導流到付費商店是一個很好的方式來增加收入。利用 GitHub 和 ComputeGate /market/ 或 /shop/ 建立一個清晰的付費商店，讓使用者能夠方便地購買進階技巧包和其他資源。
