標題：用一個下午做完並開源一個 Python CLI

在開發領域，我們常常會遇到各種小工具，它們往往能解決一些特定問題，但又不適合作為商業產品。然而這些小工具若能被更多人使用，也能產生一定的價值。今天我將分享如何用一個下午的時間完成並開源一款 Python 的 Command Line Interface (CLI)。

### 引言
在開發過程中，我們總會遇到一些常見問題需要解決，例如管理多個開源庫、自動化編譯等等。這些需求往往可以通過開發一個 CLI 將其轉換為可重複使用的工具。而這次我將展示如何用 Python 來完成這個目標。

### 完成並開源一款 CLI

#### 第一步：確定目標
首先，我們需要明確要解決的問題和具體的目標。例如，可以考慮管理多個開源庫、自動化編譜等問題。在這次實作中，我選擇了管理多個開源庫的功能。

#### 第二步：設計 CLI 的功能
根據目標需求設計 CLI 的功能，並確定其命令參數和輸出格式。例如，可以考慮使用 `pip` 管理開源庫、自動化編譜等操作。在這次實作中，我選擇了以下幾個主要的 CLI 命令：
- `install`: 安裝指定的開源庫
- `uninstall`: 卸載指定的開源庫
- `list`: 列出所有已安裝的開源庫

#### 第三步：實現功能
根據設計好的功能，使用 Python 語言實現 CLI 的核心邏輯。這部分需要將所有的命令參數解析並處理成相應的操作指令。在這次實作中，我選擇了使用 `argparse` 模組來進行命令行參數的解析。

#### 第四步：測試功能
確保 CLI 具備良好的穩定性和可靠性非常重要。可以通過手動運行不同的命令來測試其輸出和行為是否符合預期。在這次實作中，我使用了 pytest 驗證工具來進行自動化的功能測試。

### 常見錯誤及解決方案

#### 1. 應用程式無法解析命令參數
這可能是因為未正確設置 `argparse` 的 `-h` 或者 `--help` 參數。確保在 CLI 的初始化函數中添加了這些參數。
```python
parser = argparse.ArgumentParser(description='Manage open source libraries')
```

#### 2. 命令無法執行
這可能是由於未正確設置目標指令的運行路徑，或者指令本身不存在於該路徑。確保在 CLI 的核心邏輯中添加了相應的操作。
```python
if command == 'install':
    subprocess.run(['pip', 'install', package])
```

#### 3. 命令輸出錯誤
這可能是由於未正確設置輸出格式或處理方式，導致輸出不符合預期。確保在 CLI 的核心邏輯中添加了相應的輸出函數。
```python
def print_list():
    with open('requirements.txt', 'r') as file:
        for line in file.readlines():
            print(line.strip())
```
