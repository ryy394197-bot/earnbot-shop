# 用一個下午做完並開源一個 Python CLI

Python 是一種強大的程式語言，被廣泛應用於數據分析、機器學習、科學計算和自動化腳本等領域。如果你熟悉 Python 的基本概念並且有足夠的時間投入，你可以使用它來建立自己的命令行介面（CLI）工具。

在本文中，我將分享如何用一個下午的時間從頭開始開發一個簡單但有用的 CLI 工具。這個工具可以幫助你自動化日常任務，並有可能成為你的開源專案之一。此外，我們還會探討一些常見錯誤以及如何避免它們。

## 開始前的準備

在開始之前，請確保以下條件已達成：

1. 安裝 Python：你可以從 https://www.python.org/ 下載最新版本。
2. 建立一個 GitHub 訂閱者：這是存放我們開源工具的地方。如果你尚未建立，請前往 https://github.com/signup 新增帳號並完成設定。

## 3-5 個實作段落

### 第一步：決定功能需求
首先，明確你的 CLI 工具要執行什麼功能。例如，你可以設計一個工具來整理電子郵件或自動化日常報告生成。

### 第二步：架構規劃
接下來，考慮如何組織代碼和資料結構以實現你所設定的目標。使用面向對象編程（OOP）可以讓程式邏輯更加清晰明確。

### 第三步：開發核心功能
根據功能需求開發 CLI 工具的核心功能。注意要保持簡潔且易於理解，這樣才能吸引用戶使用你的工具。
```python
import argparse

def main():
    parser = argparse.ArgumentParser(description='Simple email organizer')
    
    # 增加命令行參數
    parser.add_argument('email_file', type=str, help='Path to the email file')

    args = parser.parse_args()

    with open(args.email_file, 'r') as f:
        emails = f.readlines()
        
    print(emails)

if __name__ == "__main__":
    main()
```

### 第四步：測試與修正
在開發過程中，不要忽視測試。使用 unittest 模組來驗證功能是否正確運作。
```python
import unittest

class TestEmailOrganizer(unittest.TestCase):
    
    def test_read_emails(self):
        with open('test_email.txt', 'w') as f:
            f.write("From: test@example.com\nSubject: Hello")
        
        emails = EmailOrganizer().read_emails('test_email.txt')
        self.assertEqual(emails, ['From: test@example.com\nSubject: Hello'])

if __name__ == "__main__":
    unittest.main()
```

### 第五步：分發與開源
完成開發後，將 CLI 工具上傳到 GitHub。你可以設定 GitHub Actions 來自動化測試和打包過程。
```yaml
# .github/workflows/python-app.yml
name: Python application

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  build:

    runs-on: ubuntu-latest

    steps:
      - name: Checkout code
        uses: actions/checkout@v2

      - name: Set up Python
        uses: actions/setup-python@v2
        with:
          python-version: '3.8'

      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          pip install -r requirements.txt

      - name: Test code
        run: |
          pytest
```

## 常見錯誤與解決方案

- **問題：代碼過於複雜**
  確保遵循 SOLID 原則，保持程式明確且可維護。
  
- **問題：測試不足**
  記得為重要功能建立全面的測試用例。
