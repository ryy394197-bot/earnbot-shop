## 第一步：確定你的 CLI 工具用途

要開發一個 CLI 工具，首先你需要明確它的用途。例如，你可以開發一個用來自動清理系統垃圾文件的工具、一個用來生成 Markdown 文件的工具，或者一個用來查詢天氣的 CLI。

**建議**：選擇一個你已經熟悉，或者有興趣深入研究的領域。這樣你在開發過程中會更容易遇到問題，並快速解決它。

**工具選擇**：我們將使用 Python 和 `argparse` 來開發一個簡單的 CLI 工具。

---

## 第二步：建立專案結構與基本功能

1. **初始化專案**：
   ```bash
   mkdir my-cli
   cd my-cli
   python3 -m venv venv
   source venv/bin/activate
   pip install argparse
   ```

2. **建立 `main.py`**：
   ```python
   import argparse

   def main():
       parser = argparse.ArgumentParser(description="一個簡單的 CLI 工具示範")
       parser.add_argument("--help", action="store_true", help="顯示幫助訊息")
       args = parser.parse_args()

       if args.help:
           print("此 CLI 工具的用途為示範，請查看 GitHub 專案以了解更多。")
           return

       print("CLI 工具已執行，歡迎使用！")

   if __name__ == "__main__":
       main()
   ```

3. **新增 `setup.py`**：
   ```python
   from setuptools import setup

   setup(
       name="my-cli",
       version="0.1.0",
       description="一個簡單的 Python CLI 工具示範",
       author="你的名字",
       author_email="your.email@example.com",
       packages=["my_cli"],
       entry_points={
           "console_scripts": ["my-cli=my_cli.main:main"],
       },
   )
   ```

---

## 第三步：打包與上傳到 GitHub

1. **初始化 Git 專案**：
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   ```

2. **建立 GitHub 專案**：
   - 在 GitHub 上新建一個專案（例如 `my-cli`）。
   - 將本地專案推送到 GitHub：
     ```bash
     git remote add origin https://github.com/yourusername/my-cli.git
     git push -u origin master
     ```

3. **新增 README.md**：
   - 在 GitHub 專案中新增一個 `README.md` 文件，並寫入簡短的說明、安裝方式與使用範例。

---

## 常見錯誤與解決方法

- **忘記安裝依賴**：確保你的 `setup.py` 中正確列出所有依賴項目。
- **CLI 命令無法執行**：請檢查 `entry_points` 是否正確，並確保 `main.py` 的路徑正確。
- **GitHub 專案未公開**：確保你的專案是公開的，這樣別人才能看到並使用你的工具。
