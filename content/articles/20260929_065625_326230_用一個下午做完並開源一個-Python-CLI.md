實作段落 1：設定專案結構
首先，建立一個新的 Git 版本控制專案。可以考慮使用 `git init` 命令來初始化一個新專案。
接下來，在專案目錄中創建必要的文件夾和檔案：
```
.
├── .github/
│   ├── workflows/
│       └── main.yml
├── LICENSE
├── README.md
└── src/
    └── cli.py
```

在 `src/cli.py` 中，我們可以開始編寫 CLI 的程式碼。以下是一個基本的範例：
```python
import click

@click.command()
def hello():
    """Say hello."""
    print("Hello, world!")

if __name__ == "__main__":
    hello()
```

實作段落 2：添加功能與測試
我們可以根據需要為 CLI 增加更多功能。例如，若要實現一個簡單的計算機，可以在 `src/cli.py` 中加入以下程式碼：
```python
import click

@click.command()
@click.argument("number1")
@click.argument("number2")
def add(number1, number2):
    """Add two numbers."""
    print(int(number1) + int(number2))

if __name__ == "__main__":
    hello()
```

常見錯誤
在開發過程中可能會遇到一些問題。以下是幾個常見錯誤及其解決方法：
- 未正確設置 Git 版本控制：確保專案目錄已初始化為 Git 版本控制，並使用 `git add .` 和 `git commit -m "Initial commit"` 命令來管理更改。
- 無法在命令行中執行 CLI：確認是否已經安裝了 Python 以及 cli.py 可執行檔。可以使用以下命令檢查：
  ```
  python -m pip install click
  python src/cli.py
  ```
