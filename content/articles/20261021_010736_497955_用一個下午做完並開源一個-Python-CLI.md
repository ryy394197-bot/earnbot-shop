### 二、實作步驟：從專案建立到功能實現

1. **建立專案結構**  
   使用 `pip` 建立一個虛擬環境，並安裝必要套件，如 `click`（用於處理 CLI 命令）或 `argparse`（用於解析命令參數）。

   ```bash
   python -m venv venv
   source venv/bin/activate
   pip install click
   ```

2. **撰寫 CLI 功能**  
   使用 `click` 套件可以輕鬆建立 CLI 命令。例如，一個簡單的 CLI 工具可以這樣寫：

   ```python
   import click

   @click.command()
   @click.option('--name', prompt='請輸入你的名字', help='顯示你的名字')
   def greet(name):
       click.echo(f'Hello, {name}!')

   if __name__ == '__main__':
       greet()
   ```

3. **測試與優化**  
   在本地執行這個 CLI 工具，確認功能是否正常。你可以加入 `--help` 功能，讓用戶知道可以使用的參數。
