### 引言
Python CLI 是一種非常強大的工具，可以讓我們輕鬆地在命令行中執行程式碼。然而，對於初學者來說，建立自己的 Python CLI 可能會感到困難和令人困惑。本文將分享一個簡單的方法來完成這個任務，並分享開源的範例。

### 步驟 1：設定環境
首先，確保你的電腦上已經安裝了 Python 和 pip。你可以從 https://www.python.org/ 下載最新版本的 Python。之後，使用以下命令安裝 pip：
```
python -m ensurepip --upgrade
```

### 步驟 2：建立新的 CLI 工具
在你想要儲存 CLI 工具的地方（例如，在同一個目錄下創建一個名為 `my_cli` 的新目錄），使用以下命令建立新的 Python 檔案：
```
python -m venv my_cli_env
source my_cli_env/bin/activate
pip install click
touch my_cli.py
```

### 步驟 3：編寫 CLI 工具
現在，你已經有了一個名為 `my_cli` 的新目錄和一個空的 `my_cli.py` 檔案。在這個檔案中，你可以開始編寫你的 CLI 命令。以下是一個簡單的例子：
```python
import click

@click.command()
def hello():
    """Say hello to the world."""
    print("Hello, World!")

if __name__ == '__main__':
    hello()
```

### 步驟 4：測試你的 CLI 工具
現在，你可以使用以下命令來測試你的 CLI 命令：
```
python my_cli.py
```

你應該會看到輸出 "Hello, World!"。如果一切順利，那麼恭喜你已經成功地建立了自己的 Python CLI！

### 步驟 5：開源你的 CLI 工具
一旦你完成了 CLI 工具的建立，你可以考慮將它公開在 GitHub 上，讓其他人也能夠使用和修改這個工具。以下是如何操作：
```
cd my_cli
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/yourusername/my_cli.git
git push -u origin main
```

### 常見錯誤
1. **找不到 cli 命令**：確保你已經在終端機中啟用了你的 virtual environment（virtual environment）。
2. **命令未找到**：確保你的 CLI 工具已經正確地儲存並且你正在正確地呼叫它。
