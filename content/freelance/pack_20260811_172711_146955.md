**技術／自動化接案起步包**

**對象**:熟悉 Python CLI 和內容創作的朋友，對簡單自動化有一些興趣的人。

**包含**：

1. **履歷 120 字定位**
	* 簡短地介紹你的專長和經驗
	* 可以用來應聘或聯繫客戶
2. **3 個可接服務項目與報價區間（TWD）**
	* 利基文章撰寫
		+ 報價區間：500-1,000 TWD
		+ 範例內容：針對特定行業或主題進行文章撰寫
	* 社群發文稿撰寫
		+ 報價區間：800-2,000 TWD
		+ 範例內容：創造社群發文稿來吸引目標受眾
	* 免費檢查清單設計
		+ 報價區間：300-600 TWD
		+ 範例內容：根據客戶需求設計免費檢查清單
3. **開發信範本**
	* 可以用來與客戶溝通和確認合作細節
4. **作品集 README 大綱**
	* 介紹你的作品和經驗
	* 可以用來展示你的專長和創作能力
5. **報價單欄位**
	* 服務項目：_____（選擇一項）
	* 報價區間：_____ TWD
	* 付款方式：_____（選擇一個或多個）
6. **什麼案子不要接**：
	* 需要大量手工操作的案子
	* 需要長時間監控和跟蹤的案子
7. **合約最低條款提醒**
	* 任何合約都需要明確的條款和支付細節
	* 客戶和提供者都應該清楚了解合作的內容和要求

**注意事項**：

* 不要保證接案量或固定報價
* 每個案子都需要個性化的服務和設計
* 交流和溝通是非常重要的部分，務必保持客戶關係
