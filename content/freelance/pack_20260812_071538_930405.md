**技術／自動化接案起步包**

**對象：**

* 會 Python CLI、內容、簡單自動化的人
* 對 AI 技術和自動化感興趣的企業或個人

**包含:**

1. **履歷 120 字定位**
	* 一份簡潔明確的履歷，突出您的技術和經驗
2. **可接服務項目與報價區間 (TWD)**
	* 三個可接服務項目：
		+ ComputeGate 上傳自動化
		+ 免費檢查清單生成器
		+ 自動文檔編輯工具
	* 每項服務的報價區間：500 ~ 2000 TWD
3. **開發信範本**
	* 一封完整且適合使用的開發信範本，讓您能夠與客戶溝通您的需求和預期
4. **作品集 README 大綱**
	* 一份詳細的 README 檔案，大致敘述您的作品集內容和優點
5. **報價單欄位**
	* 一份完整且適合使用的報價單範本，讓您能夠準確計算與客戶的費用
6. **什麼案子不要接**
	* 個人或企業對於您的技術有任何懷疑或質疑的情況
	* 客戶要求您不合法行為的情況

**禁止保證接案量**
	* 保證接案量會給客戶誤導，讓他們預期您能夠完成更多工作，從而影響您的健康和關係。

**合約最低條款提醒**
	* 請注意您與客戶的合約內容，特別是最低條款，以避免任何不必要的風險或糾紛。
