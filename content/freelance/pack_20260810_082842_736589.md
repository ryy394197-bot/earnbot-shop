**技術／自動化接案起步包**

**對象：**

* 會使用 Python CLI 的人
* 具有內容創作和簡單自動化經驗的人

**包含內容：**

1. **履歷（120 字定位）**
	* 描述您的技術背景、興趣和專長
	* 提供您的接案目標和期望
2. **可接服務項目與報價區間 (TWD)**
	* 服務項目一：自動化工具開發
		+ 报价区间: 5000 - 15000 TWD
	* 服务项目二：内容生成与优化
		+ 报价区间: 3000 - 10000 TWD
	* 服务项目三：数据分析与可视化
		+ 报价区间: 4000 - 12000 TWD
3. **開發信範本**
	* 對客戶的需求進行詢問和確認
	* 提供開發過程中的進度報告和變更管理
4. **作品集 README 大綱**
	* 介紹您的技術背景和專長
	* 展示您完成的案例和成果
	* 提供聯繫資訊和邀請合作
5. **報價單欄位**
	* 接案時間
	* 工作小節
	* 選項與費用
6. **什麼案子不要接**
	* 違反法律或規範的項目
	* 需要大量人工確認或審核的項目
7. **合約最低條款提醒**
	* 必須簽署合約前提供明確的報價和期限

**注意事項**

* 禁止保證接案量，以避免違反平台規範
* 依照客戶需求進行服務，務必遵守相關法令和規範
