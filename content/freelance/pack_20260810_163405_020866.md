**技術／自動化接案起步包**

**對象**:熟悉 Python CLI、內容創作和簡單自動化的人，準備從事技術／自動化接案工作。

**包含**:

1. **履歷 120 字定位**
	* 簡明你的技術背景、技能和專長
	* 透露對技術／自動化的熱情和期望
2. **3 個可接服務項目與報價區間（TWD）**
	* 服務項目：
		+ 自動化流程創造：幫助客戶優化業務流程並實現自動化
		+ AI 助手開發：設計和開發AI助手來提升工作效率
		+ 資料分析工具建設：提供專業的資料分析工具以便客戶更好地理解數據
	* 報價區間：
		+ 自動化流程創造：3,000 ~ 10,000 TWD
		+ AI 助手開發：5,000 ~ 20,000 TWD
		+ 資料分析工具建設：8,000 ~ 30,000 TWD
3. **一封開發信範本**
	* 對客戶的需求進行初步了解並確認合作方向
	* 透露你的技術能力和專業知識
4. **作品集 README 大綱**
	* 敘述你以前做過的相關案例
	* 亮點展示你的技術和創造力
5. **報價單欄位**
	* 服務項目
	* 報價金額
	* 交付時間表
	* 說明事項
6. **什麼案子不要接**
	* 已經有其他承諾的案件
	* 需要大量資源和時間的案件
	* 有法律風險或不合法需求的案件

**禁止保證接案量**

請記得，技術／自動化接案需要根據客戶需求進行定制，所以保證接案量並不是一個健康的選擇。著重於提供高質量服務和滿足客戶需求。

**合約最低條款提醒**

請務必與客戶簽署合約，並明確規定最低條款，以保護你的權益和利益。
