**技術／自動化接案起步包**

**對象：**熟悉 Python CLI 和內容創作、簡單自動化的人，希望入手技術接案的你！

**包含內容：**

1. **履歷 120 字定位**
 對自己進行定位，讓大家知道你的專長和強項。
2. **3 個可接服務項目與報價區間（TWD）**
	* 項目 1：自動化服務
		+ 描述：幫助客戶自行建立自動化系統
		+ 報價區間：10,000 - 50,000 TWD
	* 項目 2：內容創作服務
		+ 描述：為客戶撰寫相關內容，例如文章、社群發文稿等
		+ 報價區間：5,000 - 20,000 TWD
	* 項目 3：技術支援服務
		+ 描述：提供客戶技術支援，解決問題
		+ 報價區間：2,000 - 10,000 TWD
3. **開發信範本**
	* 提供一個樣板讓你可以向客戶提出您的需求和意見
4. **作品集 README 大綱**
	* 介紹你的作品集內容，包括每個項目的描述和報價區間
5. **報價單欄位**
	* 列出需要填寫的欄位，例如客戶名稱、服務項目、費用等
6. **什麼案子不要接**
	* 介紹哪些案子不適合你接手，例如需要過長時間的案子或是需要高成本的案子
7. **合約最低條款提醒**
	* 提醒你一定要在每個合約中加入最低條款，以保護自己的權益

**注意事項：**

* 禁止保證接案量，讓客戶能夠自由選擇服務。
* 請務必根據實際情況進行報價和定位。

這個起步包將幫助你開始你的技術／自動化接案之旅！
