技術／自動化接案起步包

對象：會 Python CLI、內容、簡單自動化的人。

包含：

1. 履歷 120 字定位
   - 將自身技能與專長簡明扼要地展現

2. 3 個可接服務項目與報價區間（新台幣）
   - 確保內容、簡單自動化、其他特定需求等
   - 每項服務具體描述及相關範例

3. 開發信範本
   - 設計簡潔明瞭的開發信模板，包含合作意願與提案

4. 作品集 README 大綱
   - 提供基本框架，方便整理並分享作品

5. 报價單欄位
   - 預先設定好報價單格式及欄位

6. 「什麼案子不要接」清單
   - 列出不適合的項目或需求，避免浪費時間

7. 合約最低條款提醒
   - 確保合約中包含基本保障與責任範圍

禁止保證接案量。維持簡潔，勿過於冗長。
