自動化接案起步包
目標：具備 Python CLI 能力，能撰寫內容、簡單自動化的初階自動化工程師。

包含：
1. 120 字定位履歷範本
2. 優質 3 種服務項目及建議報價區間（TWD）
3. 開發信範本
4. 作品集 README 構思指南
5. 报價單欄位設計
6. 該接的案子與不該接的案子明確標示
7. 合約最低條款建議

注意：
1. 不提供保證接案量，僅供起步使用。
2. 本包不含自動化工具代碼，僅提供開發信、合約範本等基本文件。

請根據自身能力選擇適合的項目，並善用此資源開闢自己的技術事業。
