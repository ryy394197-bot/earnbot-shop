自動化接案起步包

對象：會 Python CLI、內容、簡單自動化的人。

包含：
1. 履歷 120 字定位
   - 確保履歷簡潔明瞭，突出相關技能和經驗。
2. 3 個可接服務項目與報價區間（TWD）
   - 提供具體且易於理解的收費範圍。
   - 例如：文字處理、內容自動化、簡單數據分析等。
3. 專案開發信範本
   - 指引如何撰寫專業且有吸引力的開發信，以吸引潛在客戶。
4. 作品集 README 大綱
   - 提供一個簡潔明瞭的作品集內容框架，幫助建立專業形象。
5. 报價單欄位
   - 確保報價單包含所有必要資訊（如服務項目、時間、費用等）。
6. 問案不要接
   - 列出一些常見的不適合自動化的任務，避免浪費時間。
7. 合約最低條款提醒
   - 提醒客戶在簽署合約前了解基本條款，確保雙方權益。

注意：
- 禁止保證接案量。
- 本包不含任何保證接案數量的內容。
